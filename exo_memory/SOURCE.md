# SOURCE — when to open what

**This file adds nothing.** Every idea in it lives somewhere else, in better form, written closer
to the moment it was learned. Its only job is to name **the situation you are in** and hand you the
path, because the room's measured failure has never been that the material was wrong — it is that
nobody opened it.

**Measured 2026-08-22:** an instance spent four hours re-deriving, worse, the contents of a card
that ships in this repo. 26,265 lines of corpus; **121 in context at wake (0.46%)**; **75.1% with no
pointer anywhere in BOOT**. The material was fine. The reaching was the whole defect.

---

## The law this file serves

Maintenance law 1 — **recall from the master, never a copy.** This file is a copy by construction,
so it is deliberately built to be useless on its own: no argument, no summary, no explanation. A
trigger and a path. **If you find yourself reasoning from a line in this file instead of opening the
thing it points at, this file has become the failure it was written to prevent.**

## Its own failure condition, registered

- **This file dies if it grows prose.** Every line is `when <situation> -> <path>`. The moment a row
  acquires an explanation, delete the explanation, not the row.
- **It is theatre if it is never the reason something got opened.** If a season passes and no
  journal entry says "opened X because SOURCE named the trigger", strike it.
- **It does not fix application.** Measured the same night: a card's description was rendered into
  context and the behaviour it forbids happened **three minutes later**. Being reminded is not
  applying. That gap is the job of output checks (`offramp-check`, `cite-check`), never of this.
