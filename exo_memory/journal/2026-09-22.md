Then the rows already displaced were recovered. C's `ledger-union.js` unioned by whole row (L071): **lap 506 → 720,
board 31,749 → 35,101**, backups byte-identical, attic untouched, verified twice — by C's tool and by a raw-line script
of the librarian's that shares none of its code. L075 found the same disease in seven more ledgers and L076 restored

585 · precompact 209 · vantage 108 · return 27). On D the same union recovered **35,059 of D's own rows**, displaced by
the 09-09 migrate (D106).

**Nine of the ten remaining append-only ledgers were marked fast-forward (L074)**; `dispatch-gate.jsonl` was NOT, because
its quarantine rewrites it (`consonance/hooks/dispatch-gate.js:431`) — the one file where the rule would have jammed
