### The app was down, and the cause was the ultrareview's own highest-ranked fix

The keeper returned after three days dark and opened with *"needed to use cmd to repair
consonance."* The symptom, in his words: **the panes in the terminal weren't there and Main
wouldn't load.**

The cause was finding #1 of the 2026-08-11 ultrareview — the one the audit called *the most serious
in the set* and *land it first*. The vulnerability was real: the OS media-session title and artist
reach `innerHTML` in `app.js`, and the webview runs `csp:null` with `withGlobalTauri:true`, so a
track title is arbitrary `invoke()`. **The patch added `const escapeHtml` at the top level of
`app.js` while `term.js` already had `function escapeHtml`.** Plain `<script>` tags, not modules,
one shared global scope — a redeclaration SyntaxError, and **term.js never executed.** term.js owns
`attachPane`, `makePaneEl`, `panes` and `addPane`. The workspace vanished.

**The twelfth line on the audit's scorecard, and the worst one: finding real, fix catastrophic,
every instrument silent.** The audit verified that the vulnerability EXISTED. Nobody verified that
the PATCH RAN. 267 Rust tests and six JS suites were green throughout, because not one of them
loads the frontend. It was found by a human looking at a blank window.

### The repair, and the instrument that would have caught it

An instance working from `C:\Users\zackn\OneDrive\Desktop\606` found it and fixed it: one
`escapeHtml`, in term.js, upgraded to 5-char escaping so attribute contexts are safe, and the
reasoning left in `app.js`'s header where the next person to add an escaper will read it.

Verified rather than accepted — exactly one declaration across `ui/`, no `type="module"` anywhere,
and all six of app.js's call sites nested inside callbacks rather than at load. Then two additions:

- **The script order swapped, term.js first,** because the dependency runs one way. With app.js
  first it worked ONLY because every call site happened to be deferred; one top-level call would
  have been a ReferenceError at load, **swallowed**, because term.js's entry point at `:995` is a
  bare `try { ensureListeners(); } catch (_) {}`.
- **`ui/scripts-load.test.js`**, 4 cases. Parsing the app's own scripts as one shared scope models
  the browser faithfully for this class: top-level `let`/`const`/`class` collide across separate
  scripts exactly as when concatenated, while `var` and `function` may repeat.

Mutation-tested against the real historical defect, not merely asserted:

```

restore the old app.js-before-term.js order                        -> 3 passed, 1 FAILED

```

Landed as `9cbe33f`. The other 16 files of the review diff are still held.
