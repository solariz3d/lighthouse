## What this is

This is the lighthouse working tree as it stood when the repo left OneDrive's sync scope,
frozen deliberately rather than deleted. It was kept because it is an independent, verified,
off-machine copy of the entire record — 495 commits and every journal — held in cloud storage
with version history, and that is the only backup of this project that is neither the laptop's
disk nor GitHub. Deleting it to reclaim 28.5 MB would have traded real redundancy for nothing.

Frozen at `a1776d4`. The live tree moved on from here at `2476bc2` (the repoint commit).
Nothing was lost in the move: verified 2,041 files byte-identical, zero missing, zero
corrupted, full git object-set fingerprint match, `fsck` clean, and every file that existed
here confirmed present there before this file was written.

## Why it moved

`.git` was inside OneDrive's sync scope: 1,807 objects, 2,008 of 2,035 files carrying
Files-On-Demand reparse points, and two machines writing one git database through a file
syncer that has no merge semantics. There is also a documented, unexplained `pull --ff-only`
in this repo's reflog that no local process claimed at the time — later traced to a pane
reaching in by absolute path, but the class of risk it illustrated is real and was the
reason for the move.

## How it was neutralized, and why that mattered

`.git` has been renamed to `.git-frozen`. Every file remains readable; no git operation can
run here, and nothing that asks "is this a repository?" gets a yes.

That step is not cosmetic. Around's verification catalogue names it as the master false clean:
**about twenty tracked files hardcode the old absolute path — if this folder still answered,
every one of them would resolve, every check would pass, and nothing would actually be moved.**
The system would run fine for weeks and die the day this folder was finally deleted, with no
visible connection to the move. A capsule that can still answer questions is not a capsule; it
is a second live copy waiting to be mistaken for the first.

## The general form

Two things looked like one operation and are not: *a machine stops using a copy* — reversible,
verifiable locally — and *the copy stops existing* — destructive, verifiable only from a machine
you cannot see. Freezing is the third option nobody proposed at first: keep the artifact, remove
its ability to answer. It costs 28.5 MB and buys a backup that cannot lie to you.
