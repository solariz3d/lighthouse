and the check at `:1320`). The fix's `moveRecipe` sets `rec.piece = textHash(text)` for whatever recipe sits under the old
name. It never checks that the recipe matched the old file (`rec.piece === textHash(orig)`). So a rename turns a recipe
that was rightly refused into one that is used.
