## What it does
- **Who:** the chair or the librarian only. `CONSONANCE_PANE` equal to MAIN_SID `0c0c0c0a-0000-4000-8000-000000000a01` or LIBRARIAN_SID `0c0c0c0b-0000-4000-8000-00000000115b` (a test pins both to `main.rs`), else, with no pane variable, the cwd is `…/instances/main` or `…/instances/librarian` (exact, no subdirectory). A pane id that is neither fixed id is a committee pane and is ignored whatever its cwd. **Every other session (A–K panes included) is ignored with no row and no output.**
- **Which turns:** only a turn whose last prompt is the KEEPER's. Not a chair or pane ring (`[chair:`, `[pane:`, `[librarian:`, `[sync`, `[lap `, including a ring pasted under `<pasted_content>`), not a keep-warm, not a slash command or other machine form (D199 `keeper.js`'s forms), not a machine notification, and not a turn a notification STARTED while the seat was idle (told apart by what precedes the notification: an assistant message with no tool call = an ended turn; a tool result = work still running, so the keeper's turn continues through it). The bare reply `ok` and an empty reply pass untouched.
- **It fires on** a reply naming: a **path** (drive path, an `exo_memory`/`consonance`/`dev`/`src`/… path, or `a/b.ext`), a **sha** (7–64 hex with a letter AND a digit), a **commit** (`commit <hex>`, which also catches an all-digit sha), a **count** (`N/M` or `N of M`, not a path or a date with a year), a **percentage**, a **version** (`v1.2`, `1.2.3`). Plain prose, a lap id, a decimal like 0.868 and a bare number do not fire. Tokens are clipped to 80 characters, scrubbed of key shapes, a sentence-final full stop is trimmed, max 12 per reply.
- **Then it needs a FINAL `Sources:` line** (the last non-empty block; any case; markdown emphasis tolerated) whose items match calls of that turn. **REUSE, NOT COPY:** the turn reader (`readTurnEntries`, `turnCalls`, `isPrompt`), the item grammar (`parseSources`) and the matcher (`itemMatches`) are the SOURCES gate's, taken with `require('./sources-gate.js')`, so the two cannot drift: it installs beside it (`To = hooks\\…`), and if the require fails the hook fails open with an error row.
- **SHADOW:** it writes one row per evaluated Stop to `C:\Consonance\data\reply-slot.jsonl` and **prints nothing and exits 0 on every path**. The kinds: `pass-notoken`, `pass-matched`, `pass-none` (a `Sources: none` on a reply that names a claim: allowed, recorded as `none: true`), `would-block-missing`, `would-block-unmatched` (the row names the unmatched items), `would-block-empty`, `skip-keepwarm`, `skip-active`, `skip-not-keeper-<ring|machine>`, `skip-no-prompt`, `error`. A row carries a sha256 of the reply, its length, the flagged tokens, the unmatched items, counts: **never the reply text** (a test greps the ledger for a unique sentence).
- **The block is BUILT and tested but not ON:** `verdict({live:true})` returns `{decision:'block', reason}` naming the claim kinds and the unmatched items; `main` passes `live: !SHADOW` with `const SHADOW = true`. Going live is a ruling plus that one constant, and the tests would catch a flip that breaks the shape.
- **The loop guard works in shadow too:** `stop_hook_active` true → a `skip-active` row, no evaluation, and the transcript is not even read.
- **Fails open on every error** (garbage or empty stdin, no `last_assistant_message`, no or unparseable transcript, no data dir, an unwritable ledger, `sources-gate.js` missing, an exception, a 5 s watchdog): exit 0, nothing printed, an error row where it can log.
