## What was built (all in `game/`)
**The record:** `game/world/run_record.h` / `.cpp`, plus 95 lines in `game/world/world_app.cpp`.
- **When it's written:** a run that ends is written to `game/runs/` (git-ignored, beside `game/config/`). That covers a catch, a fall into a void, and leaving it (a restart, a new seed, closing mid-run).
- **The files:** each run is two files named for when it began.
  - `run-YYYYMMDD-HHMMSS.txt` is for reading, with these fields:
    - `result` ("caught by the interceptor #2 after 22.44 s");
    - `build`: the commit, stamped at every build, `+changes` when the checkout has uncommitted edits;
    - `began` (UTC), `seed`, `level`, `ticks`, and both fingerprints;
    - `[summary]`: the end, the seconds, the kind and number of the chaser that made the catch, and where it happened;
    - `[close calls]`;
    - `[dials]`: every curve;
    - `[params]` and `[world]`, at 9 significant digits, enough to give each float back exactly;
    - `[events]`: every event the chase logged, as `chase::to_text`.
  - `.dzr` holds the input, tick by tick, with the simulation fingerprint at the end (`sim::write_replay`, the gym's replay format).
- **Kept:** the last 20 runs (`kRunsKept`).
- **Not written by a read-only app:** so the self-tests and captures leave nothing. checked: after the dz-world self-test, `game/runs` does not exist in the worktree.
- **Marked runs:** a run whose dials were changed while it went on is flagged `dials_changed = 1`, because it can't be replayed exactly.

**The replay:** `dz-world --replay-run FILE` (or `last`, the newest kept run), with `--window SECONDS` (default 20). See `game/world/main.cpp`.
- It plays the run again headless from the door: no window, nothing written. It checks both fingerprints against the record.
- Then it prints every half second of the window: each chaser by kind and number, its distance, where it was relative to the way the player was going, its mode and its speed.
- After that, the chasers that were ahead (within 45°) and within 12 m in the last 5 s, and the chase's events in the window.
- Exit code 0 only when the run replays to both fingerprints.

**The override:** `game/config/world.local.txt` is read after `world.txt` (WorldApp's constructor).
- A broken local file is reported in a notice and not used.
- The names it sets are never written into `world.txt` by Save.
