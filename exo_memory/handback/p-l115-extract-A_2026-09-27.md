## 4. The sentence rule (one rule, also written in `key.json`)

> A sentence is a non-blank line, further split after `.` `!` or `?` (plus any closing quotes, brackets, `*` or backticks)
> where whitespace follows and the next character is not a lowercase letter. Lines that are only markup — a code fence,
> a horizontal rule, a table separator row — are not sentences. The part-separator lines this extraction inserts are not
> sentences.

- Checked on 6 fixed inputs (`scratchpad/l115/t.js`, 6/6): abbreviations like "e.g. x" stay whole, a backtick path `a.js` is not split, `**bold.**` closes a sentence, and an empty input gives 0.
- **Not checked against any human split of the real replies** (§6).
