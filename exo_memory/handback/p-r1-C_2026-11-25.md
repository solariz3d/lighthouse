it means a fresh install no longer registers it; a machine that has it registered keeps it until it is removed by hand, and `-Check` there now says
EXCLUDED BUT LIVE. GATES.md and GUIDE.md said "it ships on"; both now say it is off and how to turn it on.

**To turn it back on:** delete the two `; Excluded = 'R1 …'` clauses in `dev/shell/install.ps1` and run
