## How a row's figure is read (S/table.js)

- A case's figure is the best of the test's own retries, because a case passes when any try does. A row's figure is its worst case.
  - "p95 ms by look/case/length" JSON → the greatest per-key least.
  - "p95 a / b" → the least.
  - "worst frame a / b" (release-frame) → the least.
  - drag-frame row 9 and the drag-cost rows → the rolling p95, with the test's own ratio in brackets.
  - Sculpt's "(bars: p95 6 …)" text is stripped first. My first parse read it as a value and gave 6.0 for every row 4a run. I caught
    that by eye and fixed it before this table.
- Rows with no ms figure are left out: drag-frame row 5, release-frame row 3, preview-lod row 3, sculpt row 5, drag-cost 3/3j.
- **Paired diff** = batch − main within one round. The table gives the median of the three, and then the three. **Spread** = max − min
  over a tree's three rounds. **Verdicts** are each run's own ok/FAIL/todo. All figures are ms.
