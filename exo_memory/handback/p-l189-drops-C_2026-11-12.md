## 1. Registered first (12:4x local, before any harness code or result)

**The seeds:** N = 24, seeds 1 to 24, default dials (`GenParams` as the game makes it, no biome forced).
- The block for each seed is chunks x −1..0, z −1..0, storeys 0..3 (72 m square, four storeys).
- Its geometry is built from two chunk layers lower, four storeys, so a fall's depth can be read.

**What is tried:**
- **(a) Stepping off.** The real controller (the walk proof's world: `sim::World` from the generated chunks) stands
  on every walk-graph node in the block. That is every cell floor and every flight end or landing. It walks, without
  jumping, toward each of the four neighbouring cells, unless the edge that way is a Wall or solid mass (`EdgeKind`
  Wall or None), which it cannot leave by.
- **(b) Dropping onto.** The body is let fall from 0.5 m above every node.

**What counts:**
- An attempt is a **deep drop** when the body comes to rest, or leaves the built geometry, more than one storey
  below where it started: more than 3.5 + 0.5 m.
- A deep drop is **designed** when the cell it fell into, at the storey it started on, is a kind the generator means
  as a void: `CellKind::Void` (an atrium's air), `Abyss` (a void corridor), `Shaft` (a ladder shaft) or `Well` (a
  light well). The kinds are read from `Generator::cell`, never by hand.
- Every other deep drop is **unintended**.
