# Review

Two authors were each given the task below, on a clean checkout at the base commit, and asked to fix it test-first and commit.
Their diffs against the base are `review/X.diff` and `review/Y.diff`; each author's own hand-back is `review/X-handback.md` and `review/Y-handback.md`.
This directory is a clean checkout at that base (`ac7ab4a`). You may apply a diff (`git apply review/X.diff`), run tests, and reset (`git checkout -- . && git clean -fd -e review`). Run every test command through the lock wrapper: `node review/hr.js -- <command>`. If anything would open a browser or an Electron window, pass --headless and --mute-audio.

## The task the authors were given

In src/core/extend.js the edge clamp bounds each side to [max(lo, floor), cap]. With a numeric transition shorter than the piece, a side brought from −45.5° back to 0 rings above 0 (a control at +8.277°) and ends at +0.670° with slope 0.585, so the next piece is not plain and a lap is refused at the seam. A side asked back to 0 must land at exactly 0, from below as it does from above.

## What to answer

For each diff: is it correct; what edge cases does it miss (name them, with a probe if you can run one); did it cut or weaken a test; how much would you have to change to land it. Then: which would you land, X, Y, or neither, and why in two lines.

Write your whole answer to `review/VERDICT.md` in this directory, and also print it as your final message.
