## What it implements (registration §3, verbatim rule in code)
- **Open** = `Read` tool_use in a transcript under `C--Consonance-instances-librarian*`, path with `\` → `/` lower-cased ending in `exo_memory/<rel>`, timestamp ≥ W0 (and ≤ W0+14 d). Any directory named `third-place` is never entered. `read_ledger.jsonl` is not used.
- **Entry** = a `- <rel>  (N lines)` line in the shelf's NOT CARRIED section, up to the `THE INDEX IS WINDOWED` line. **NEW** = after minus base; **OLD** = base's `map/ journal/ loop/` entries; F3's set = NEW under `handback/`.
- **F1:** 0 NEW opened fires; ≥ 3 helped; 1–2 undecided, not rounded up. **F2:** OLD opened ÷ OLD < 4.1% fires. **F3:** 0 newly listed hand-backs opened fires; ≥ 1 reports the count.
