## What landed

- **The skin pick.** An inline head script draws `Math.random()` into `window.__t180MelodyPick` and sets
  `<html data-theme>` from `['aqua','skyline','glass','aurora']` before first paint.
  - createSound gets `pick:` from that same draw.
  - The boot then runs `applyTheme(document, sound.melody)` (`app/lib/theme.js`).
  - An unknown or missing melody removes the attribute, which gives SIGIL.
- **The token reader** (`app/lib/tokens.js`):
  - `css` / `rgba` / `floats` / `alpha` / `solid`, each with today's colour as a required fallback;
  - parses hex, rgb/rgba and `color(srgb …)`, so the floats stay exact;
  - reports an unreadable token once;
  - re-reads when `data-theme` changes;
  - is shared per window as `__t180Tokens`.
- **The tokens** (on `:root` in `app/index.html`; SIGIL's values equal the old literals):
  `--ink --on-ink --on-ink-strong --veil --veil-rule --guide-bg --guide-text --guide-label --sky --fog --road-edge --road-tie --ground-grid`.
  These are the names posted on the board.
- **The 3D view.** The renderer has `setTheme` / `themeFrom` for the sky, fog, road edge, tie and grid. preview.js applies them at mount and on every token change.
- **Chrome colours.** The 21 CHROME hexes and 5 rgba are on tokens across 13 files, following the rulings at plan :2362.
  - spawnsui uses `--warn` / `--ok`.
  - The guide outline follows `--accent`.
  - The meaning colours stay literal.
- **Label boxes.** labels.js reads `--ink` and recolours the label boxes already made when the skin changes.
- **Mutant R15** in `core-mutation.test.js` is re-pointed to `T.alpha('--ink', 0.94, '#0b0d11')`. Its rule changed with the code; the mutant was not weakened.
- **The skins.** `app/themes/skyline.css` and `app/themes/aurora.css` are styling only, and the page links both.
- **CHANGELOG.** `[Unreleased]` gets Added and Changed entries.
