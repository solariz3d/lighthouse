### 3. What changed (the diff, old → new)
- **Before the install** (`look0 = ReadLook(Shortcut)`, ahead of closing the app and running `/S`): reads the desktop `.lnk`'s working folder and icon while it still points at the rebuilder.
  - If it already points elsewhere, or cannot be read, the rebuilder's own folder and `…\t180-track-builder.exe,0` (what the shortcut was set to by hand on 11-06 and 11-07).
- **After the exit-code check, before the stamp and Launch** (`RestoreShortcut(Shortcut, look0)`): target = its own exe (`Assembly.GetExecutingAssembly().Location`), arguments empty, that working folder and icon, saved.
  - A missing shortcut → a yellow note naming the path and the rebuilder's exe; the run carries on.
  - A failed write → the same, with the error.

- **WScript.Shell is reached by late binding** (`Type.GetTypeFromProgID` + `InvokeMember`), so the compile needs no extra reference, the same as before.
- **A check-only switch,** `--restore-shortcut <read-from.lnk> <target.lnk>`, runs only those two routines and prints the read-back. It never pulls, builds, installs or launches.
- Everything else is unchanged.
