## The hunter film's hang (pane C's, 77 minutes)

**Cause:** with no model given, `--capture-pair` on a chaser asks `run_chase_track` for the end fingerprints. It then stepped
`while (!record_done && script_running)`. C's `run-20261112-202937` is an older build's record that no longer plays to the bit,
so its run ends before its inputs do. An ended run steps no more ticks, the record is never done, and the loop never ends.
