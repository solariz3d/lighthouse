## Each one checked against the code (`app/core/panel.js` `extendOptions` and `crossStartM`, d576-a)

**Bank, cup, left and right edge are F:** `XS_START = {phi, c, e, er}` → `crossStartM`, with `startShapeOf` for the shape.
- **The ramp asked:** `max(F_RAMP_M = 300, 3.4 × |change| / roll amber)`, capped at half the piece (but never under `min(20 m, piece)`).
- **The ramp laid:** in three quarters of that (`laidOf`, 225 m for 300). The code's own comment measures his piece "done by 234.5 m". **So the librarian's "about 235 m (or half a short piece)" stands as the code has it.**
- **Added for these four, because the code does it:** "a big change takes longer". The roll bar takes over past about 82° of change, where 3.4 × 82 / 0.934 ≈ 300 m.
- **Added for the bank alone:** "may then use more of the piece". `bends` lets the bank's cap go to the whole piece when F within half would roll past the amber. Cup and edge keep the half-piece cap.

**Width:**
- **As it will ship** (C's d574-c, `e3bdf48`): `ch === 'w'` takes `min(F_RAMP_M, max(min(20, piece), piece / 2))` with F's shape, and no roll bar. So the librarian's text exactly, with no "big change" clause.
- **On d576-a, the base of this branch, width still reaches its value within 20 m.** **The width tooltip is right only once d574-c has landed: land d574-c with or before d581-o.**

**Turn and climb:**
- **Read as a rate:** `AT_START_M` = 20 m, or the piece if shorter (`Math.min(AT_START_M, out.length)`).
- **Read as a corner** (the panel's default), a typed value other than 0 sets `turnDeg` / `climbDeg` and no `kh` / `kv` target. The loop at `if (atStart[f] && targets[ch] !== undefined)` then never reaches it, so the box does nothing.
- **A corner of 0** is a rate target of 0, and the box applies. Hence "a turn other than 0".

**Edge start and tube sweep:** not in `XS_START`, so `Math.min(AT_START_M, length)`: 20 m, or the piece.

**Numbers used:** only 20 m (`AT_START_M`, interpolated from the constant) and "about 235 m" (the code's measured F finish). No other number is in any tooltip.
