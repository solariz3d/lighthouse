## 3 · The settings oddity `{ "hooks": [] }`: RULING

**It is an install.ps1 logic bug, not a PowerShell quirk.** Owner A; the fix is A's, named here, not made.

**Cause:**
- `dev/shell/install.ps1:815-817`: when an event array is new (`$groups.Count -eq 0`), it seeds a placeholder `[pscustomobject]@{ hooks = @() }`. That placeholder is meant to receive an UNMATCHED hook.
- `:825-832`: for a Matcher entry, the code looks for a group with that matcher, finds none, and APPENDS a new matcher group.
- The placeholder is never used, and `:882` / `:901` write it out empty.
- So it appears exactly when the first-ever entry on an event carries a Matcher. PreToolUse was absent before; the second reader is its first entry.

**Harmless today. Checked:**
- The settings loaded with it present: the second-reader hook fired in fresh AND already-running sessions (§4).
- Other hooks kept working: this pane's UserPromptSubmit pulse fired after the install.
- A group with no matcher and no commands runs nothing.
- Re-running the installer does not grow it: with `Count` > 0, no new placeholder is seeded.

**A latent hazard in the same code (the real reason to fix it):** `:873` sends an UNMATCHED entry to `$groups[$groups.Count - 1]`, the LAST group.
- On PreToolUse the last group is now the second reader's matcher group.
- So any future PreToolUse hook registered WITHOUT a Matcher would be silently appended into the `call_librarian|call_chair` group and scoped to those two tools. It would not fire on every tool as written.
- That is a wrong-scope bug that would pass a casual look. *Inferred from the code; not exercised.*

**The fix for A:**
1. Seed the placeholder only for non-Matcher entries (`if ($groups.Count -eq 0 -and -not $e.Matcher)`).
2. Have unmatched entries target a group with NO matcher (creating one if none exists), never "the last group".
3. Optionally, drop groups whose `hooks` is empty before the write at `:901`.
4. Add a test: a fresh PreToolUse with a matcher yields one group, and an unmatched entry after it lands in a matcher-less group.
