## THE FIX THAT WAS WRONG, and the instrument that caught it

`P-GEN-RED-FIRST` proposed scoping the waiver to the `#[cfg(test)]` region. Measured before
choosing:

    grep -c '#\[cfg(test)\]' consonance/src-tauri/src/main.rs   -> 40
    grep -c '^\s*mod tests\b' consonance/src-tauri/src/main.rs  -> 0

Forty attributes, interleaved through 10,153 lines, no `mod tests`. **The test file's own docstring
calls the block "a small tail" — it is not**, and region-scoping would mean a forty-site brace model
of Rust, which that same docstring says is the thing it exists to avoid trusting.

So I narrowed by CLASS instead: drop MACHINE for every fixture. The argument was clean — a filename
discloses nothing, an absolute path does. The mutation run:

    HEAD (class-narrowed)   main.rs MACHINE=0  leaks=10  REFUSED
      leak files: lap-row.test.js 1 · memory-sweep.test.js 7 · second-vantage.test.js 2

All ten are assertion literals: `normPath('C:\Consonance\lighthouse\...')`, an encoded-cwd fixture
name `C--Users-user-OneDrive-Desktop-fixture`, a heads map keyed `c:/consonance/lighthouse`.
Rewriting any of them is the 2026-08-23 damage returning by a different door. **And the scope tests
stayed green while the generator refused to build** — staging is written before the refusal check,
so every content assertion read a tree the generator then declined to emit.

## THE FIX THAT LANDED — cut by WHY a file is a fixture

    fixtureKind(rel)
      'whole'  fixture by PATH   (*.test.js, anything under tests/)  -> DANGLING, MACHINE, RECORD waived
      'rust'   fixture by EXTENSION only (.rs)                       -> DANGLING, RECORD waived; MACHINE not

The waiver's justification — *"this is the data the assertion keys on"* — is true of the first kind
and false of the second. No model needed, and it generalises to the next Rust file.

Second half: **`demachine()` joined the fixture branch** with three named patterns, so the live doc
comments are rewritten rather than merely refused. Measured: it fires on `main.rs` only, 3 rewrites.

**And its existing rule had never fired.** `/the repo moved out of OneDrive on \d{4}-\d{2}-\d{2}
because \.git was inside the/` required one space where main.rs:404-405 wraps the sentence across a
`///` continuation. A guard that cannot match is indistinguishable from no guard, and this one read
as coverage. Repaired to a single-line form.

**3. `portable-paths.baseline.json` — the entry KEPT and made honest, not deleted.** Proven dead

reachable. Same failure shape as the demachine rule that could not fire, found the same day: a guard
that reads as coverage.

- **The `unportable` MACHINE alternation is belt to a brace.** With MACHINE unwaivable in live Rust

  test. Stated rather than implied.
- **`fixtureKind` is still path-shaped.** A `.rs` file placed under a `tests/` directory gets the
  full waiver — correct for `arch_test.rs`, and an assumption if someone ever puts live code there.
- **The 5.8 MB is arguable and I made the call one way.** Excluding the `.jsonl` would have been the
  degenerating move; shipping them is most of the consumer tree's weight. Re-open it on the size,
  never on the gap.
