## 1 · THE SURPRISE

`consonance/hooks/jev-flags.js` finds the chair's and the librarian's session ids by reading
`path.join(__dirname, '..', 'src-tauri', 'src', 'main.rs')`, i.e. **relative to where the hook file sits**. My D108 recipe
(`install.ps1:289-290`, and `p-d108-l2only-A_2026-09-22.md` §3.4) says to move it into `$files` with `To = 'hooks\jev-flags.js'`.
That COPIES it to `~/.claude/shell/hooks/`, as every `$files` hook entry does (`install.ps1:93-98`). From there
`../src-tauri/src/main.rs` does not exist, so `seatIds()` returns nulls. `flagLines()` returns `[]` for any reader, and the hook
exits 0 silently, **on every prompt, forever**.

silence, so it never breaks a prompt), but that is exactly what hides this one.
