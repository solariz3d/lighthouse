**Opt-out list rules:**
- containment, not a name prefix (`/proj` does not cover `/proj-other`);
- **case-insensitive under win32 rules.** Measured: `path.win32.relative` already compares case-insensitively, so
  choosing `path.win32` IS the rule.

**`ledgerDir`: ledgers are STATE.** They are append-only rows that must outlive a restart, and they are neither
documents nor cache.
- **Windows: `%LOCALAPPDATA%\jev`,** falling back to `<home>\AppData\Local\jev`. It is local, not roaming, and today's
  Jev store already lives under `%LOCALAPPDATA%` (design item 8).
- **macOS: `~/Library/Application Support/jev`,** Apple's place for app-created data.
- **Linux: `$XDG_STATE_HOME/jev`, else `~/.local/state/jev`.** The XDG spec's STATE directory is defined for data that
  should persist between restarts and names logs and history. A relative `XDG_STATE_HOME` is ignored, as the spec
  requires.
- **All paths come from the `env` and `home` passed in.**
- **For Consonance:** it keeps today's store by setting `ledgerDir` in its config.

**Config file:** `<home>/.jev/config.json`.
- `~` expands against the home PASSED in.
- Any other path must be absolute; a relative one is refused, because it would depend on where Jev happens to run.

**Loud failures, never a silent fallback. Each names the file:**
- invalid JSON;
- a config that is not an object;
- a wrong value (`judge`, `audience`) or a wrong type (`dream`, `sessions`, `optOut`);
- a relative path;
- an http gateway;
- **an unknown key.** A typo like `judgee` or `optout` that silently did nothing would leave someone believing they had
  opted out.

**Only an ABSENT file means defaults.**

**THE KEY IS NOT CONFIG.**
- `load` never reads or returns it.
- A key-like field in the file (`key`, `apiKey`, `AI_GATEWAY_API_KEY`, `token`, `secret`, `password`, also inside
  `gateway`) is refused. The message says to use the environment and **does not echo the value** (tested).
- Tested with a live-looking key in the `env` passed in: the result contains no trace of it.
