## 4. The instrument: `consonance/tools/dupe-scan.js` (new, 136 lines; kept, my call)

**Method** (the file's header says it in full):
- each file is tokenised, with comments dropped and string and number literals normalised;
- a window is 8 code lines holding at least 40 tokens and at least 4 distinct lines, so a run of closing braces is not a duplicate;
- a window whose text occurs in 2+ non-overlapping places is duplicated;
- continuing windows on the same pair of places join into a block, and overlapping blocks join into a cluster;
- a second pass reads identifiers as I.

**Kept because** the fix laps will need a re-measure, and the room had no clone instrument (pointer 3).

**Not in this commit:** a `dupe-scan.test.js` and a `consonance/tools/README.md` line. The order said I own only the tool file.

**The known-answer check instead** (S/d554/known):
- a 12-line block copied into a second file, shifted by a comment;
- the same block with every name changed, in a third file.

    checked: node consonance/tools/dupe-scan.js A=S/d554/known/a B=S/d554/known/b --json → literal: 26 of 43 lines, one cluster 13 × 2 at a/one.js:3-15 and b/two.js:7-19; renamed: 42 of 43, one cluster 14 × 3 (all three files)

**Its limits, said plainly:**
- Regex literals are tokenised as operators.
- A `${…}` inside a template literal is read as part of the string.
- Both are consistent between copies, so they cannot make a clone, but they can blur one.
- Only JavaScript is read. The 41k lines of Rust (`main.rs`) are outside this scope.
