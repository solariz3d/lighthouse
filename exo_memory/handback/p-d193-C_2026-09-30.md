## 1. THE CHECK THE CHAIR ASKED FOR: "a value left as shown acts as a target equal to the current value" is NOT blank-equivalent

**Checked in code and by test.**
- A blank field makes `src/core/extend.js` **continue** the channel: `cont(s) = v + m·s`, the end value AND the end slope.
- A target `T = v` gives the Bloss blend `(1 − S)(v + m·s) + S·v = v + (1 − S)·m·s`. That is a **different piece whenever the head's slope
  m ≠ 0**: after a brush, on an opened real track, or wherever a turn or bank is still changing at the end.
- **Cup has a second, bigger trap.** Any `c` target makes the new piece a CUP piece (`extend.js`: `cup = targets.c given || …`), even a
  target equal to the rendered edge. A legacy track's next piece would render with the cup profile instead of the legacy one; E's seal
  measured those shapes differing by up to 4.458°.
- Both are shown by the last test in §3. A literal target equal to the shown bank changes the new piece's `phi` channel. A cup target
  equal to the shown edge makes the next piece `cup: true`, where the blank keeps it legacy.

**So the rule built is the packet's fallback, made THE rule.** A field whose text is exactly the text that was shown sends **no
target**: blank-equivalent, bit for bit. The comparison is against the shown STRING, never a re-parsed rounded number. A changed value is
a target, as before. A cleared field is blank. Typing the shown value back makes it untouched again.

**Consequence the keeper should know** (inferred, not asked): a field that shows, say, turn `12.35` on a head where the turn is still
changing does not HOLD 12.35 if left alone. It keeps changing the way the track was going, as blanks always did. To hold a value, type it.
That is the same behaviour as before, now with a number in the box.

## 2. What was built

- **`app/core/coreshell.js`: `shell.headState()`**, read only. It returns the head's END state in the core's units: `kh` and `kv`
  (rad/m), `phi` (rad), `w` (m), `c` (degrees; a legacy piece's is the edge it renders, from `D.endState`). On an empty track it returns
  the first piece's START as `extend.js` makes it: family bowl, level, straight, `WIDTHS.bowl` = 31 m, and
  `c = D.legacyEdgeDeg('bowl', 31, RATES.bowl)`.
- **`app/core/panel.js`:**
  - **Units:** turn and climb in °/100 m, bank and cup in °, width in m.
  - **Precision:** two decimals, trailing zeros dropped, never "-0".
  - **Refresh:** whenever the document object changes (Extend, Undo, Redo, open, a brush stroke, a close), in `draw()`.
  - **Options:** Extend, the ghost and the readout all use one options function (`asTyped`: untouched → `''`), so they stay live and
    agree. It is exposed read-only as `panel.options()` for the tests.
  - **Length is not a channel and is not refreshed.** It keeps what was typed and starts at **100 m**, today's default, kept on purpose:
    five 20 m knot spans, long enough for a Bloss transition to read as a curve, short enough to place a piece at a time.
  - The field and button titles now say what a shown value does.
