## What Part 2 asked, and where it is

- **`beginBrush({ tool })`** resolves the 14 tools to (mode, channel, family): `SCULPT_TOOLS` in `app/core/coreshell.js`. The tool decides, whatever `mode`/`channel`
  come with it (B's Stretch sends `mode: 'rate', channel: 'length'`). An unknown tool is refused by name (`BAD_TOOL`). Calls without `tool` are D244b's, unchanged.
- **The family sets the guard:** shape keeps the D244b centreline guard (every step and at the end); local and route have none. `centreline.js` itself is unchanged:
  its call sites in the shell now run for the shape family only.
- **Smooth's channel is the last tool's** (`lastToolChannel` in the state); a `channel` given wins; with none it is refused (`SMOOTH_CHANNEL`). The family follows the channel.
- **A route tool on a CLOSED lap:** the drag runs on the lap OPEN (a frozen copy with `closed: false`, so `brush()` never closes per step; `sculpt.js` untouched).
  `endBrush` only starts the release job and returns (`state.brush.closing`); the job: `close(doc, { window })` (the pieces the drag changed) in the close worker when
  there is one, else on the page a microtask later; refused → the whole-lap close once with the window protected (`whole`, `edited`); refused again → the drag is
  dropped whole, `ROUTE_NO_CLOSE: …`, the track exactly as before. The re-closed lap lands as the drag's present: ONE undo step. `brushRelease()` is its promise
  (tests; the page reads the state). An edit or Esc meanwhile drops it. `closejob.js runClose` and `closerunner.js` take a `window` (sent only when asked).
- **Run windows:** `sculptInfo()` gives `from`, `to`, and `index`/`id` of the run's middle road piece; `beginSculpt({ tool })` on a run selection, and
  `beginSculpt({ channel | tool, from, to })` as B's page calls it, brush the run (centred on it, as wide as it). The selection's longWay rule already keeps a run inside
  the lap, so a run never crosses the start line here.
- **A radius change mid-drag:** `brushRadius(r)` sets r and takes no step; the page's `brushTo` in the same frame re-runs from the same base. (D335's ratio is now
  read per radius.)
- **Unchanged:** `endBrush`'s commit (the C2 anchor line), `D.beginDrag`/`dragTo`/`endDrag`, the D335 ratio on one piece, V5.

## For the design (P, the librarian)

- **The window close is rarely the path for a small route edit.** On a test lap (a 300 m straight, four quarter turns, a 60 m straight, closed), a Bend's own
  window re-closed the lap alone only when it was wide (pieces 1-5); every narrower window (1, 1-3, 1-4 pieces) was refused and the whole-lap fallback closed it,
  which moves pieces outside the window. So "only the window's pieces move" (design §4.3) holds for wide windows; for a one-piece Bend the keeper will usually get the
  whole-lap close, as today's rate brush does. Measured with the real close (sculpt-tools row 5 uses the window that does close; row 6 the fallback).
- **D335's ratio** is read for a one-piece window as before; for a RUN window it is not applied (the bump on a multi-piece window peaks within a whisker of the
  delta). inferred, not measured on a run.
