## What it says (inferred from four rows on a quiet machine, not from a harness run)

1. **The copy is not the cost here.** About 100 ms of a ~21 s mutant, 0.5%. Option 2 (copy less) would save under 6 s across 59
   mutants in this harness. The two other big harnesses copy differently (`mutation.test.js:170-173`,
   `core-close-mutation.test.js:76-80`) and are unmeasured.
2. **The inner run is the cost, and almost all of it is tests the mutant is not judged by.** Each mutant runs all 76 tests of
   `core-shell.test.js` and `core-readout-display.test.js`, and its verdict reads one named test. Narrowed to that name, the inner
   run took 127–536 ms instead of 20–22 s, roughly 40–175× faster, and all three mutants were still caught.
   - Scale, inferred: 59 mutants × ~0.3 s narrowed, plus the control run whole (~22 s), gives about a minute for this harness's
     mutants, against 1,991 s in part 1's full run. That full run was under 4-wide load, so the real gain is smaller per second
     but of the same order.
3. **The risks of option 1, named before anyone builds it:**
   - A narrowed run executes only the matching tests. If a named test depends on state an earlier test in its file left behind,
     it can behave differently alone. A mutant "caught" whole could then read NOT CAUGHT narrowed, or the reverse. The bar's
     per-file applied/caught/NOT APPLIED = 579/579/0 is the check that catches this, but only if the counts are compared per
     mutant, not as totals.
   - `caughtBy` is a substring the harness matches with `includes`. `--test-name-pattern` is a regex, so it must be escaped
     (the script does: `measure-one-mutant.js`, `esc()`). It also matches suite names, so a describe block named alike runs whole.
   - The crash stand-ins (D352–D354) assert NOT TESTED readings from a run's shape: dead files, a file's own exit. Their
     readings were built on whole runs, and a narrowed run changes which tests report. Those four tests need to stay whole, or be
     re-proved narrowed.
4. **The control stays whole**, as the librarian's option 1 says. It is the one run whose verdict is "every test passes".
