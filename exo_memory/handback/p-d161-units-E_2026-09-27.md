## THE UNIT RULE AS BUILT — the plan's words, and the choices I fixed before drawing

**The plan's words:** a pair is **one tool result** (cut to 30 lines, with `[… N lines cut]`) and the **first sentence of
the next assistant text that states a number, unit, count or verdict**, taken from **the four panes' `.jsonl` on D, 09-14
onward**.

**What the plan left open, fixed in `draw.js` before any unit was drawn:**
1. **Files.** The four panes' main session files on D (A `6fe15f0a…`, B `12fb81f6…`, C `0845a868…`, E `a2122153…`).
   **All rows in them count,** including rows carried from L. "D's own pane transcripts" is read as the files on D, per the
   plan's parenthesis. The machine is recorded per unit, in the sealed file only.
2. **Window.** Tool-result timestamps from **2026-09-14T00:00Z up to 2026-09-27T16:36:30Z** (the plan commit `e9cb884`),
   so this lap's own work is excluded.
3. **Tool results = COMMAND outputs only (Bash, PowerShell).** Q3's wording asks about "a command's output", so Read, Edit
   and MCP results are not pairs. Image or empty results are excluded (0 found).
4. **"The next assistant text"** is the first assistant message after the tool result whose content has a text block. It
   pairs only if the **immediately preceding significant row is that tool result**. Thinking-only rows are skipped. Any
   other user row (the keeper, a hook, another tool result) breaks the pair.
   - So in a parallel batch, only the **last** result pairs with the text.
   - A turn that goes straight to another tool call has no pair (the "no text next" column).
5. **"States a number, unit, count or verdict":** within that text block, outside ``` / ~~~ fences, lines are split into
   sentences at `[.!?]` + space. The first sentence qualifies if it holds **a digit**, a **number word** (zero–twenty,
   none, both, all, every, half, twice, once, dozen, hundred, thousand), or a **verdict word** (pass, fail, green, red, ok,
   error, broken, works, fixed, clean, correct, wrong, match, missing, empty, succeed, success, identical, unchanged, and
   their inflections). Case-insensitive, whole words.
6. **Privacy filter (the repo is PUBLIC).** A pair is ineligible if its output, its sentence or its command contains a term
   from a list kept **outside the repo** (`C:\Consonance\sealed\q3_2026-09-27\private_terms.json`, sha256 `5e802f4e…`).
   The list is private project names and email/key patterns. **41 pairs were excluded.**
   - The written file was then scanned for key, token, password and email patterns and for the list's terms: **0 hits.**
7. **Output text is verbatim**, including ANSI colour escapes (42 raw ESC bytes; no NUL, so `text-census` is unaffected).
   Readers see `[33m`-style codes where a tool coloured its output.
8. **Format.** Each unit is `## Unn`, an **Output** block (a fence longer than any backtick run inside it) and a
   **Sentence** blockquote. The header restates Q3 verbatim from the plan.
