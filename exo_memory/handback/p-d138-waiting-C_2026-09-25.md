## 1 · JS — clause 6 in `chain-status.js`, live at the next hook load

**The test,** from each seat's own transcript: take its **last message row**.
- A message row is `type` `user` or `assistant`, and not `isSidechain`.
- Attachment, system and snapshot rows are skipped, because they are written around a turn and are neither side of it.
- If that last message is an assistant row with a `tool_use` named **AskUserQuestion**, the seat is waiting on the
  keeper.
- Its `tool_result` is a later `user` row, so **it clears the moment the answer lands.** A new prompt typed over the
  question also clears it.

**The line:** `librarian waiting on YOUR answer since 02:04`, and `A …` / `chair …` for other seats. It rides with
clauses 4 and 5 and prints with no lap open. It never says stall or "turn runs": STALE fires only at 24 h and is
untouched.

**Finding the transcript** is `board-digest.js` `findTranscript` (`hooks/board-digest.js:192`), copied as this file
copies everything: scan the project dirs for `<session id>.jsonl`. It is not a second mapping. Two bounds keep it
cheap:
1. **Only live seats are read:** the chair, the librarian and lettered panes with a row in the board tail that is
   already read here. `letters.json` holds 13 sessions, and only 6 of all the seats looked up have a transcript at
   all. The blind scan (15 lookups × 585 project dirs) measured 96 ms, most of it on the dead ones.
2. **`*Consonance-instances*` dirs are tried first.** This is an ORDER, not a filter; a test pins that a transcript
   elsewhere is still found.

The transcript is read by its **last 256 KB** (`FILE_TAIL_BYTES`, the digest's figure), never whole, and a torn first
line is skipped.

**Measured cost:** `node consonance/tools/chain-status.js` takes 172–184 ms, against 164 ms for HEAD's version on the
same store, so **about 10–20 ms per prompt.**

**A launch ends it:** a question opened before the app last started (`stick-waiter.lock`, the proxy QUEUED uses) died
with its dialog.

**Hermetic tests:** the existing tests call `line()` with no projects dir, which would read the REAL
`~/.claude/projects`. So the file is now overridable (`CONSONANCE_PROJECTS_DIR`), and **the test file points itself
and every CLI it spawns at an empty temp dir**. A test pins that. No old test was edited.
