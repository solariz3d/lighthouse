## 4 · THE QUESTION IS HALF-MALFORMED, AND THE HALF THAT IS SOUND IS THE HALF ALREADY ANSWERED

**"Bloated" has no meaning without a container, and only one of the two nouns has one.**

- **"Is the corpus bloated?" is well-formed here** precisely because the room built the container first: a shell
  with a byte ceiling, a floor, and an eviction rule. That made the question measurable, it was measured three
  times (§2 items 1-3), and the answer each time was *over*.
- **"Is the code bloated?" is not answerable as asked**, because nothing on disk says what the code is supposed to
  fit inside. A raw line count cannot settle it, and here is why, measured now rather than asserted:

  ```
  $ wc -l consonance/src-tauri/src/main.rs                                        16671
  $ awk '/^#\[cfg\(test\)\]/{i=1} i{n++} i&&/^}$/{i=0} END{print n}' main.rs        7239
  ```

  **7,239 of 16,671 lines — 43.4% of the room's largest source file — are inside `#[cfg(test)]` modules.** Calling
  that file bloated by its length would be calling its tests bloat. *(The 16,671 is the figure I saw in the key
  fragment, §0; I re-derived it. The 43.4% is my own.)*

**What would have to be defined before the code half can be asked at all — in the order the corpus half was built:**

1. **A container.** What must the code fit in, and why that number? The corpus got one because a real thing broke
   (a shell that would not fit a pane). Nothing has broken on the code side, which may be the honest reason the
   question was never put.
2. **A denominator that is not lines.** The one the room already uses is the UI census's tests-to-instrument ratio
   (`p-ui-guard-census:62`, 40.1%, with the Rust side noted as *"closer to one-to-one"*). Bloat is then *behaviour
   shipped without a guard*, which is measurable and already has an instrument.
3. **A cost that lands on someone.** Corpus bloat costs a pane its context at every spawn, which is why it kept
   being measured. Until code size costs something nameable — build time, a surface nobody can review, an
   instrument nothing routes to — "bloated" stays an aesthetic judgment with no falsifier.
