## 2 · WHY jev-flags DOES NOT REQUIRE THE SHARED RESOLVER

jev-flags is installed as **one file** into `~/.claude/shell/hooks/` (`install.ps1:147`). A `require('../tools/jev-room.js')`
from there is exactly the L089 bug: silent, and green on `-Check`. So it keeps its own lookup, and **a parity test pins the
two to the same answer:** `jev-flags.test.js` "L105 PARITY". It runs five fixtures (room_path valid, room_path to nowhere, no
room_path, no config, config not JSON) and compares the **file AND the route (`tier`)**.

**The route matters, and I found that by a surviving mutant.** At first the test compared only the file. Mutant F2 (jev-room
climbs one directory level) survived it: jev-room missed through room_path, fell back to the checkout beside it, and reached
the same main.rs by a different road. Comparing the tier catches it.

**The alternative, named for the librarian:** install `jev-room.js` beside the hook as a `Lib` entry. That needs an
`install.ps1` entry and an install, so it is not mine to do.
