## 1 · WHAT THE RULE IS FOR — read before deciding

`every_named_record_file_exists_and_every_record_file_is_named` (`arch_test.rs:500-556`) is **two rules**:

1. **A card that names `record/X.md` must name one that exists.** Its stated harm, in the doc comment: *"the guard the
   `spread/` bug went without. For weeks the room instructed every pane to read `spread/the_wave_set_loose.md` and no
   pane could: the file had never been written anywhere on any machine, and the only symptom was a pane quietly not
   reading its own counter-voice."* A dangling instruction is silent — the pane cannot tell an absent file from a file
   it failed to reach.
2. **Every `record/X.md` must be named by a card** — *"a record nothing points at is unreachable by a pane, which is
   worse than not splitting it out at all."*

**History.** `git log -S "is named by no card" -- consonance/src-tauri/tests/arch_test.rs` gives ONE origin:
**`56adc69`, 2026-08-09**, *"deck: split the record out of the two cards that were mostly record — a card is the move
you run, the record is the case"*. The split moved ~23k of dated material out of two cards, because
`trust-the-first-attention` was 88% record that every pane paid for in ceiling and almost none opened.

**The fact that decides this packet.** `git log -S 'the dated worked material behind the cards that name it' --
consonance/src-tauri/src/main.rs` returns **the same commit, `56adc69`**: the intake's own enumeration of `record/`
(`main.rs:704-720`, a `read_dir` that lists every record file into every shell) was added **in the same commit as the
rule**. So rule 2 was never about making the PATH visible — the author shipped the listing at the same moment. It is
about a record having a **HOME**: the move that opens it. That is the room's own standing rule for cards one level
down — *"give it a trigger in SOURCE.md, or retire it"* — applied to the record. A file listed in the shell with no
card that says WHEN to open it is ceiling nobody spends.

**And the intake's label is a claim this test keeps true.** `main.rs:707` calls `record/` *"the dated worked material
behind the cards that name it"*. With two orphans on disk, **that sentence was false in every shell every pane woke
into.** Amending the rule would have left the label lying; the amendment would then need to edit main.rs too.

**So: the rule is right and the corpus was wrong. The card route.** No amendment is proposed.
