## 1. The method (so every number below can be reproduced)
- A change of `c` at stage k = the `c` definition's right-hand side (`eq.def("c").rhs()`) differs from stage k-1's. Cause: MODE if the stage's summary says "the lens moves" (the Mode move, `stream.rs:1058`); PROG if the book's progression id changed at that stage; BOTH; OTHER.
- `checked:` `src/compose/harmony.rs:476` → a progression module's defs include `Def::new("c", format!("c = {}", p.mode.lens()))`, and `book::install` writes a module's defs. So a progression install can write `c`; this is why PROG is the cause, not only a coincidence of the two changes.
- Tool: `research/2026-11-05/tools/src/bin/cchange.rs` (sha256 `8c7ffac1…507e`; subcommands `fresh N salt`, `seed seed version last`, `judged dir`).
