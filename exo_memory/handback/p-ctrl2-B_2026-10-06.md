## What it does (`app/preview/preview.js`; the keeper, 14:51: "cant even click drag look around and go down")
- **Left Ctrl starts and keeps flying with the movement keys** (W A S D, Q E, Space, Shift, the arrows) **and a right-button look drag.**
  - A movement key pressed while Left Ctrl is the only Ctrl down uses its Ctrl-free action, and only if that action is fly or turn. A Ctrl+C never switches the camera, and Ctrl+L never changes the look.
  - Space with Left Ctrl is a move too.
  - **Ctrl+Space nets zero** on the up axis.
- **Only these stop it, and undo that press's descent:**
  - a **shortcut** key: whatever `app/core/keys.js` `keyAction` answers with Ctrl (Z, Y, S, Backspace). This is asked of keys.js itself, so the two lists cannot drift;
  - **the wheel** (Ctrl + wheel is still the lens);
  - a **LEFT-button** press (a handle drag, Ctrl to snap; my 64fa6cf `pointerdown` listener kept). The left button is read from `e.button`; a press with no `button` field counts as left, the cautious way. A right-button press neither blocks nor stops Ctrl.
- A shortcut key already down **blocks** Ctrl from starting (Z then Ctrl: no flight). Shift or W already down does not.
- **Only the descent is undone, and W's travel stays.** The undo used to count `dir[2]/n·k`, which is exact only for a level view. With the view pitched, `move()` scales the sum of the axes (forward and world up are not perpendicular), so the count was off: **0.397 m in the first green run**. The fix is a new read-only **`rig.free.scaleOf(fwd, right, up)`** in `app/camera/cameras.js`, the factor `move()` applies, and the preview counts `up · scaleOf(...)`. The view is restored only when Ctrl **alone** had taken it over.
- **Jump string** (`app/core/jumpplan.js:85`): a missed fall now reads "…(it needs N km/h): a warning, not a red (tune it by driving it in AC)." It said "the jump is red", which has been a warning since D250.
- Stale comment fixed in passing: the `MOUSE LOOK` comment still said the left button looked in free mode (D255 changed that).
- **README:** the Controls row says "Left Ctrl flies down instantly, like Space; a Ctrl shortcut such as Ctrl+Z puts the camera back". It does not say Ctrl must be alone, so per the packet it is unchanged.
