## 2 · Started from blackbox, and the reference
**Blackbox** (`C:\Users\nname\Desktop\blackbox\ui`), the files I started from:
- `ui/glcore.js`: the renderer's per-material uniforms (ksSpecular / ksSpecularEXP / ksEmissive / ksAlphaRef from the kn5), a hemisphere ambient, and the eye position for the specular half-vector. My renderer was already started from glcore.js in D169; the AC path follows its uniform layout.
- `ui/kn5.js`: how a kn5 stores a material property (a name, then ten floats in four groups A(1) B(2) C(3) D(4)). `app/preview/kn5look.js` reads the same layout, mirroring `src/export/kn5write.js`.
- No code was copied from blackbox verbatim.

**The reference: actools** (Content Manager / Custom Showroom, https://github.com/gro-ove/actools, Ms-PL).
- `AcTools.Render/Shaders/Includes/DarkMaterial.Lighting.Complex.fx`: `CalculateLight`, `CalculateSpecularLight`, `GetNDotH`. Ported: colour = tx·(Ambient·ambient + Diffuse·diffuse + Emissive) + pow(saturate(n·h), max(exp, 0.1))·Specular.
- `DarkMaterial.Base.fx`: `NormalSampleToWorldSpace` (2x−1, 1−2y, 2z−1 into the tangent frame). Ported.
- `DarkMaterial.Unpack.fx`: Unpack (txDiffuse), Unpack_Nm (the alpha from txNormal). Ported.
- `Kn5SpecificForwardDark/Materials/Kn5MaterialDark.cs`, `Kn5MaterialDarkNm.cs`: the property → uniform mapping; a missing property reads 0.
- `MaterialsProviderDark.cs`: which shader gets which class. ksPerPixel, ksPerPixelAT, ksPerPixelAT_NS and ksTree → ksPerPixel; ksPerPixelNM and ksPerPixelNM_UV2 → NM; an unknown shader with a txNormal sampler → NM, otherwise ksPerPixel.
- **ksMultilayer: actools has NO class for it.** The layer blend in the preview is **INFERRED** from the AC modding community's description: txMask's R/G/B/A weight txDetailR/G/B/A, each tiled by multR/G/B/A, with magicMult scaling the result. Not from actools, NOT verified against AC (§5.3 parked), and marked so in both files.
