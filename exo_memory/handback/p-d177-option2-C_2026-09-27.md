## 1 · What changed (src/geom/path.js, sha256 2fff7141c20cf3cf)
- **FRAME:** the unrolled left is the heading's left, H(θ) = (cos θ, 0, −sin θ).
  - Set at every substep and every sample; the double reflection no longer grows the frame. `doubleReflect` stays exported, unused by growth.
  - In a block's local coordinates the left is H(θ_local), and Ry(th)·H(a) = H(th + a), so every block's local start frame R0 is exactly (1, 0, 0) (`firstOf`, `nextOf`).
  - A block's shape now depends on its handles and its start pitch ONLY. The convergence rule of p-d177-rigid-C §1b therefore stops at the first tail block whose start pitch is unchanged: every edit but a pitch edit re-places the whole tail.
- **The closing twist is gone.** A closed loop's frame closes with its heading, so `buildPath` no longer spreads a twist. `path.twist` stays in the interface, always 0.
  - I first tried to keep the spread for the closure's tangent residue, and added a test for it. It failed for a real reason: a heading residue is a turn about world up, not a twist about T, so the spread had nothing left to do. The code and that test were removed; M2 changed with it (§5).
- **Error messages:** the two refusals for a closed loop (extend, sculpt) gave "its twist spans the loop" as the reason. Now they say it must still close (the connector's job). Both still contain "closed loop"; `test/geom_grow.test.js:93` matches on it.
