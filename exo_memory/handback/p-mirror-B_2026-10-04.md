## THE REGRESSION: the per-path tree goes STALE on an open track, and the gap is then wrong, silently

The tree is memoised per PATH OBJECT (`indexMemo`, a `WeakMap`, in `indexFor`). But the track model edits an OPEN track's path IN PLACE:
`geom.extendPath(path, segs)` and `geom.rebuildPathFrom(path, segs, g)` (`app/preview/trackmodel.js:96, :100`) push and truncate
`path.samples` (`src/geom/path.js:220, :305`). With no lift, the shown path is that same object, so after an extend or a brush the
preview re-plans (the bounds object changed) but `indexFor(path)` returns the tree of the OLD centreline. The queries, though, come from
the current samples.
