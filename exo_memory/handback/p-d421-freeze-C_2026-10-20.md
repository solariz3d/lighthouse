## §2 The fix (`sculpt.js`)

- `brush()`: each document's offsets are computed once per step (`offU`, `off0`) and passed to `valueAt` (new optional `off` argument), so
  the scan reads channel values only.
- `pieceOffsets()`: converts through the adapter's per-piece segment cache (`toSegments` `cache`, exact by `test/core_segcache.test.js`) in a
  module `WeakMap`. A drag reruns the brush on the same base document, and the brushed document shares every untouched piece, so a step pays
  only for the changed pieces.
  - The cache is used only when every piece is frozen (the core's documents are, all the way down).
  - An unfrozen document (read from a file, say) could be written in place, so it's converted afresh.
- The brushed document is bit for bit the old scan's (D421b).
- inferred: one edge changed. The old scan computed the offsets inside its per-sample `try`, so a conversion error there was swallowed and
  ended as BAD_BRUSH ("moves no control point"). Now such an error surfaces under its own name. Both documents have passed `checkDoc` by then,
  so I expect it never to fire.
