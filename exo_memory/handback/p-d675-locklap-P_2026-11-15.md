1. **The idle holder in the pulse.** The chair and the librarian see, at every prompt, a live lock holder that heavy-run's guard named
   idle: `IDLE HOLDER <seat> slot <k>, held <m>m, nothing under it (named <n>x, last <hh:mm>Z)`.
   - It is matched on the guard's own holder description, judged live by `status()`, and read before the no-lap exit.
   - It reuses the board rows the pulse already parses.
2. **`--run` takes a `.cmd` or `.bat` and `--priority belownormal|idle` itself.**
   - cmd.exe is started from an argument list, `/d /s /c ""<path>" <args>"`.
   - The priority is set on heavy-run's own process before anything starts. Any other value is refused, exit 2.
   - A cmd metacharacter in an argument or in the resolved path is refused, exit 2.
   - The script's own exit code is passed through.
   - The usage line names the Git Bash slash limit.
3. **`--pause --cmd "<why>" [--minutes N]` / `--resume`.**
   - A detached, hidden holder takes the exclusive hold through `acquire()` with `holdOnly`: no slot, so runs in a slot finish and new
     runs wait.
   - The record carries `pause: true` and `max_ms`, honoured instead of the 90-minute maximum (default 180, cap 720).
   - `--resume` ends a pause and refuses any other hold, exit 2. A dead pause holder is stale.
4. **`--wait-game [--max-minutes N]`.**
   - The rule: Star Citizen and acs always; dz-world, dz-gym and dz-view only with a visible window; anything under `steamapps\common`
     with a visible window; plus the profile's `games` names.
   - It exits 0 when no game runs, 3 at its maximum, and 2 on an unreadable or empty list. It only reads.
