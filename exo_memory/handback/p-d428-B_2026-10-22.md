## What changed

- **4, the blink at the press.**
  - `down` no longer clears `hover`, and `sculptHover()` returns null only once the drag is OPEN (`drag && drag.open`), not as soon as it is set.
  - `openBrush` clears `hover` when the brush takes over.
  - So the reach and the glyph stay on screen from the press to the first step past the click threshold.
  - A click (no drag) keeps the hover, as the pointer is still there.
- **5, Alt from the key.**
  - A `keydown` / `keyup` of Alt on the document sets `hover.alt`.
  - So the glyph turns to Grab's sideways axis and back without a pointer move.
  - The pointer's `altKey` is still read on each move.
- **6, one pick per move.**
  - `labels.js` now has `sharedPick(doc, win, x, y, key)`, which asks `t180-pick` once per pointer EVENT per page (WeakMap by document).
  - The labels' frame and Sculpt's hover both ask through it.
  - `hoverAt` keeps only the pointer and its event, and the station is picked when a layer first asks (`hoverStation`).
  - The key is the event, not the position, so a new move always picks again. That is how the labels' own pick worked; tests that move twice to the same place over a changed road still see the new road.
