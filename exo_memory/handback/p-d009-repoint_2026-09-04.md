**Two shape decisions, both read off the consuming tool rather than guessed:**

- The key is **`withdrawals`**, not `withdrawn`. My first draft wrote `withdrawn: []`, which is not a

  correct key would have looked like a regression.

  reported `CH4-ADDED` — a flood of false positives on a stranger's first run. Same distinction the
  manifest itself draws: withheld is not undecided.
