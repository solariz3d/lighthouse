The sweep finds child-process calls **by their literal name** (`\b(spawnSync|spawn|execFileSync|execFile|execSync|exec)\(`),
across `stick-waiter.js`, `stick-apply.js`, `tail-carry.js` and `place-conversations.js`, and has a floor of 8. **At L068

    +  const child = spawnFn(exe, [], { cwd: path.dirname(exe), detached: true, stdio: 'ignore', env: appEnv });

The regex does not match `spawnFn(`. So the sweep lost exactly the call **its one named exception is about**, the
relaunch of `consonance.exe`. Its count fell to 7 and the floor fired. **The call the sweep lost:** the 7 it still saw
were `stick-waiter.js:156, :169, :175, :223` · `stick-apply.js:161` (the carry) · `tail-carry.js:212` ·
`place-conversations.js:170`, and the relaunch at `stick-apply.js:177` was absent. **The sweep could not name that call
itself; it can only count.** The diagnosis named it, from that list and the diff. My L070 R6 recorded this red as
"unowned"; it was mine from L068.

## 1 · WHY THE SWEEP IS RIGHT AND THE CODE WAS WRONG

The sweep exists to see every child-process call. A call routed through a renamed parameter is precisely the thing a
static scan cannot read, and **its floor caught the evasion by counting**: the design working. Widening its regex to
`spawnFn` would teach it one alias and leave the next one invisible. **So the code changed, not the sweep.**

## 2 · THE FIX

    function defaultRelaunch(exe, spawnFn = null, env = process.env) {
      …
      const opts = { cwd: path.dirname(exe), detached: true, stdio: 'ignore', env: appEnv };
      const child = spawnFn ? spawnFn(exe, [], opts) : spawn(exe, [], opts);

**The real call is written out literally, and the test seam only REPLACES it** when a test supplies one. The CLI path
calls `defaultRelaunch(exe)`, so it runs the literal `spawn(exe, [], opts)` that the sweep sees. **No second exception:**
the relaunch keeps the existing one. `consonance.exe` is a GUI-subsystem program that allocates no console, and
`windowsHide` would set SW_HIDE, which could start the app itself hidden (the comment above it, unchanged). The L068
scrub (no `CONSONANCE_DATA` for the app) is unchanged.
