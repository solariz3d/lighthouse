**The harness (`ac_launch.js`), rule by rule:**
- **Refuses any track that is not `t180b_[a-z0-9_]+`,** and any folder without our `.t180b-builder.json`.
- **Rule 2:**
  - it refuses to launch without the heavy-run lock (`--heavy-run <path>` or `HEAVY_RUN_JS`, so no lighthouse path is
    committed);
  - it holds the lock through `hold()`;
  - graceful close (`taskkill /PID`) at `--minutes` (at most 9), then `taskkill /PID <pid> /T /F` of **its own child
    only**, with a 10-minute hard timeout.
- **Rule 1:**
  - it hashes, then backs up, **every `.ini` in `cfg/` and `cfg/extension/`** (60 files on D) to
    `<file>.bak-t180b-<stamp>`;
  - it writes `race.ini` only inside `withBackup`, which restores byte-exact in a `finally` and re-hashes;
  - it exits 2 if any file differs.
- **Paths:** `--ac` / `AC_ROOT` (default: the Steam path `docs/FINDINGS.md:283` already names) and `--docs` /
  `AC_DOCS` (default `<home>/Documents/Assetto Corsa`). No personal path is in the file (privacy grep over the three
  files: 0 hits).
- **`race.ini`:** an AI race. CAR_0 is an idle player at the back (`SESSION_0 STARTING_POSITION = cars`), and CAR_1..n
  are AI.
  - `REMOTE` carries `ACTIVE=0` only: no server, name or password (a test holds this).
  - `REPLAY`, `GHOST_CAR` and `BENCHMARK` are off.
- **Collected per run** into `out/ac_runs/<stamp>_<track>/` (git-ignored): `log.txt`, `custom_shaders_patch.log`,
  `race_out.json` (if written) and `summary.json` (every cfg hash before and after).
