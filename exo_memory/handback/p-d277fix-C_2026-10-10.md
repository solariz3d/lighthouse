## The change
- **The directory list becomes a named constant.** The shelf used an inline list, `["", "record", "memory", "librarian", "spread", "research", "map", "journal", "loop"]`. It is now `const LIGHT_SHELF_DIRS`, and `librarian_shelf_light_at` walks it with its behaviour unchanged.
- **The test's floor.** `light_every_pointer_resolves_to_a_file_that_exists` no longer asserts `paths.len() >= 10`. It builds its expected pointers from what this room has:
  - every `LIGHT_SHELF_DIRS` directory that `is_dir()` under the room root, which is `room_master_path().parent()`, the same root the shelf uses;
  - plus `atoms.jsonl`;
  - plus the topics directory, when it exists.
- **Each expected pointer must appear** among the paths taken from the shelf index and the memory section, so an empty or short list fails.
- **Every listed path must still exist.** That loop is unchanged.
- **A sanity floor:** at least 3 expected pointers (root, one directory, atoms). This is a guard on the test itself, not the check.
