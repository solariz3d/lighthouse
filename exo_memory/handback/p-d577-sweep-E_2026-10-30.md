## 2. Proof (a): the code with comments stripped is byte-identical

The scanner is `S/d577/jsscan.js`, written for this order, with no dependency. (S = `C:\Users\nname\AppData\Local\Temp\claude\C--Consonance-instances-sibling-07b8a48f\a2122153-a37e-41a6-a86f-534267ec0565\scratchpad\`.)

How it reads a file:
- It splits the source into code, string, template, regex, line-comment and block-comment segments.
- A `/` starts a regex unless the token before it ends an expression.
- `${}` nesting in templates is tracked on a stack.
- An unterminated token throws.

What `stripped()` does:
- It drops the comments and trims trailing blanks.
- It drops lines that end up empty.
- It never does either inside a string, template or regex.

How the scanner itself was checked:

  - comment edits ignored and code edits seen;

  - regex, including a `[//]` class;
  - block comments across lines;
  - escaped quotes;
  - unterminated tokens throwing;
