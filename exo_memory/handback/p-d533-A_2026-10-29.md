- **The head unfolds the rows, read fresh each time.**

- **Keys:** ↓ from the head reaches the first row; ↓/↑ move between rows (↑ from the first row goes back to the head); Enter picks.
- **A pick** (click or Enter) closes the menu, then opens the track (or the version), as the select's change did.
- **Escape** is the menu's own (menubar.js). It closes the menu, and closing the menu by any route (Esc, a press outside, a command) folds the list. inferred: a separate "Esc folds only the list" would mean changing menubar's capture-phase Esc. I left that alone; say if it's wanted.
- `refreshList()` after Save now refreshes the Open rows only while they are unfolded (they are read fresh on every unfold anyway).

**Look:**
- `.more-menu .menu-row` uses the Pieces menu's row hover (`rgba(255,255,255,0.05)`), which is also its focus colour.
- Each theme's existing `.pieces-menu .piece-row:hover` rule now also takes `.more-menu .menu-row:hover` and `:focus`, so the rows light in each theme's colour.
