## 4. THE FIRST CORRECTION THAT CHANGES THE FIX: `nname` IS INFLATED BY THE WORD "unnamed"

`nname` is a substring of **unnamed** (u-**nname**-d). Every raw count of `nname` — the chair's 52,
the librarian's 53, and my own first run of 61 — includes files that contain no account name at all.

    git grep -l -F nname HEAD -- . | wc -l              -> 61   raw
    git grep -P -l '(?<!u)nname' HEAD -- . | wc -l      -> 49   strict
    git grep -o -F nname HEAD | wc -l                   -> 148  raw occurrences
    git grep -P -o '(?<!u)nname' HEAD | wc -l           -> 132  strict occurrences
    git grep -P -o 'unnamed' HEAD | wc -l               ->  16  reconciles 148-132 exactly
