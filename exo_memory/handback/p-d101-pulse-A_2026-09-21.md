## 2 · WHY I DID NOT BUILD THE NOT-RUN PATH

- **It would be false.** A declared "Python absent" gate would read NOT-RUN on a machine where the file can run and pass.
  That is my own runner's rule (e), *"a MACHINE-BOUND file must not read NOT-RUN where it CAN run"*, broken by a
  declaration.
- **The runner would not catch it.** Rule (e) catches a too-strict gate by forcing it open (`JS_SUITE_UNIVERSE=force`).
  Forced, this file would still call `python`, still hit the stub, still fail, and the NOT-RUN would be accepted. The one
  probe built to catch a false NOT-RUN is blind to this particular one, because the lookup bug and the gate would share a
  single cause.
- **The fix is outside my grant.** The real fix is `pythonExe()`, not the declaration line. It is E's file (header
  "pane E"; `dfaf3e0`), so I propose it rather than widen my own grant.
