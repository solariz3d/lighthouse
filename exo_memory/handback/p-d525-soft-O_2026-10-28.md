There is one source with CSP's own words. It is the CSP wiki page the block comes from, "Tracks – Collision parameters", in the `ac-custom-shaders-patch/acc-extension-config` wiki. I fetched its raw markdown on 2026-10-29 and kept it as `csp-collision-params.md`.

The `[CUSTOM_COLLISIONS]` section of CSP's server options documents the same keys ("Available since 0.1.77, servers now can completely redefine collision parameters"), at https://cup.acstuff.club/docs/csp/misc/server-extra-options. The local CSP install's text files name none of these keys.

| key | CSP's words, verbatim | stated default or range | what it means for this lap |
|---|---|---|---|
| `SOFT_ERP` | "Error reduction parameter" | none stated (the example is 0.8; the server page's is 0.99) | **No source says what raising or lowering it does in CSP**, so it is not varied. ODE's meaning of ERP is not taken on trust. |
| `SOFT_CFM` | "Constrain force mixing, the higher it is, the softer is the collision" | none stated (the example is 0.0001; ours is 0.0002) | The one key with a stated direction: lower is stiffer, higher is softer. B and C move it. |

## 2. The four variants, and why

Each folder differs from the source only in `data/surfaces.ini` (the block, plus one comment line naming the variant) and in `ui/ui_track.json`'s name. Everything else is byte-identical; see the manifest.

- **A, the control:** the shipped block, unchanged, as `trackfiles.js:20-29` writes it: `SOFT_ERP=0.8`, `SOFT_CFM=0.0002`, `BOUNCE=0.1`, `FRICTION=0.05`, `MAX_DEPTH=4`.
- **B, stiffer:** `SOFT_CFM` 0.0002 → **0.00005** (a quarter).
  - It is the only key CSP gives a direction for, so it changes alone.
  - The factor of 4 each way, with C, is symmetric on a log scale, and large enough that a real lever should show beyond one replay's band-to-band scatter.
  - It stays in the order of magnitude of CSP's own example (0.0001).
- **C, softer:** `SOFT_CFM` 0.0002 → **0.0008** (four times).
  - The same reason as B, the other way.
  - The 4 m `MAX_DEPTH` backstop is unchanged, so a softer road still turns hard well before anything can pass through.
- **D, the shipped block plus the observed tracks' three keys:** `INTENSITY=1`, `RIGID_WITH_BODIES=0`, `RIGID_WITH_BOXES=0`, the one difference `trackfiles.js:16-19` names.
  - **My reading: probably pointless for the physics.** By CSP's words `INTENSITY` is damage, audio and visuals. A rigid flag is rigid only "if set to 1", and the car-bottom box was already measured sinking (D515), so 0 is what the road already does.
  - It is staged because it is cheap and ordered. If D drives differently from A, it is the default that would then need a source.
- **ERP is not varied in any variant.** CSP gives no direction for it, and the plan's rule is that no ODE meaning stands without a CSP source.
