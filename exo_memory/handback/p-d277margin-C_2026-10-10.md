## The change
- **The helper:** `span(text, heads, ends)` measures one section in the intake itself, from the first head present to the first end after it.
- **Pane row:** the assertion `light + 14_000 <= strict` is replaced with:
  - `light + strict's memory section <= strict + light's pointer + growth of the optional briefs`.
    - The growth term covers the freed seat up to `LIGHT_OPTIONAL_CAP` when strict's seat is under the cap.
    - The map is not allowed for, because `map_allowance_mode` can only shrink it.
  - When `atoms.jsonl` exists, strict carries a memory section (the topic map or the fallback) and light carries a pointer.
  - Light never carries strict's section.
  - **b59f01d6:** the pointer's span ends at the map OR at either strict memory heading.
- **Librarian row:** the assertion `light + 25_000 <= strict` is replaced with:
  - `light + strict's per-path index + every body strict carries outside light's fixed set <= strict + light-only notes + LIGHT_SHELF_APPARATUS_MAX (6,000)`.
    - "Light's fixed set" is `cards/` and `librarian/`. A body counts as carried when strict contains the exact `\n\n## {rel}\n\n{body}\n` piece, the format both shelves use.
    - 6,000 was already the structural bound's apparatus figure. It is now a named constant used by both assertions.
  - Strict carries the per-path index whenever the room has dated record (journal/, loop/ or map/ with any .md).
  - Light carries none of strict's dropped bodies.
- **The comments** say why, with B's hand-back cited.
