## R0: the app's `/compact` write (L218 Addendum 3; checked)

**The bytes, and how.** The close path is:

`close_small_send` → `gate_or_queue` (or, when queued, `drain_inboxes`, which writes the stored text unchanged) → `inject_to_pane` →
`deliver`.

`deliver` writes to the pane's PTY master:
1. One write, a bracketed paste: `ESC[200~` + `/compact` + `ESC[201~`.
2. Then, as a separate write `submit_delay_ms(18)` = 120 ms later, a lone `\r`.

There is no label, and no send stamp: the label and stamp are added only by the ring senders, before they reach the gate. The
NEXT-trailer gate is in `mcp.rs`'s verbs only (`trailer_gate` in `chair_inject`, `call_chair` and `call_librarian`), and this path
never passes through `mcp.rs`.

**The run.**
- **The seat:** `bin/compact_probe.rs` on a throwaway seat in a scratch folder, never a working seat. It ran on haiku, launched
  with the app's own flag (`--dangerously-skip-permissions`), and wrote exactly those bytes.
- **The seat's transcript:**
  - `11:22:59.896Z user <command-name>/compact</command-name> <command-message>compact</command-message> <command-args></command-args>`
  - `11:23:09.303Z system compact_boundary {"trigger":"manual","preTokens":38966,"postTokens":9453,…}`
  - 11.7 s after the write (`r0_transcript_rows.txt`, `r0_probe_result.txt`).
- **Two probe fixes made this possible** (L212's four probe runs never got input in):
  - **Answering the terminal's queries.** The probe now answers what xterm.js answers: ConPTY's cursor-position request, device
    attributes, the colour queries and the synchronized-output mode. L212's "inferred" cause is thereby shown.
  - **Clearing inherited markers.** Run from inside a seat, the probe passed that seat's `CLAUDE_CODE_CHILD_SESSION` marker to its
    child. The child then wrote no transcript ("Transcript saving is off — inherited CLAUDE_CODE_CHILD_SESSION marker"). The probe
    now clears `CLAUDECODE` and `CLAUDE_CODE_*`; an app pane, started by him, carries none of them.
- **Ruled out, from the chair's list:**
  - **The label:** a labelled `[chair:MAIN] /compact …` arrives as a message (the 10:55Z rows of panes A and B, the librarian's
    read). The close path writes no label.
  - **The trailer gate:** it is not on this path at all.
- **Not shown, inferred:**
  - **The terminal was the probe's, not the app's xterm.js.** The bytes reach claude the same way (the app writes to the same PTY
    master; xterm.js only draws, and answers the queries the probe now answers). His first press of the control shows it in the app.
  - **Not launched from the app itself.** The app starts a seat only on his click, and its close path only on a seat over 300k.
- **What L212's control needs changed for the write: nothing.**
