## 2. What changed (t180 d483-c, against 883c200)

| file | change | why |

## 7. The stale-key rows, and what breaks them

**`test/geom_mesh_stalekey.test.js`, new, 7 rows.**
- Each row changes one later piece, sculpts an earlier one, and asks for the full rebuild, plus proof that the change really moves piece 6. The changes:
  - a frozen profile replaced;
  - a frozen segment replaced;
  - a number changed in place in an unfrozen profile;
  - the same in a frozen profile whose arrays are not frozen;
  - a frozen profile swapped inside an unfrozen blend;
  - angles read through a getter.
- The seventh row is the control: every later piece is kept. The first six passed on 883c200 too: they are guards of the new caching, not of a bug. The getter row was added later and never ran on 883c200.
- **Correction, my own:** the first version left font ramps on. A changed profile then gave its piece a ramp from the one before, and so a new key by another road, so the shallow-freeze mutant survived it. The rows now set `rampM: 0`, and that mutant is caught.

**`app/test/ghost-stalekey.test.js`, new, 4 rows.**
- A reader changes a handed-out chord in place to what the next candidate holds; the next ghost is still where a fresh build puts it.
- `sameContent` returns true for equal content and false for any difference.
- One object reached from both sides is the same only when deep-frozen.
- `snapshot` is untouched by a later change.

Mutants added to the harnesses that run those rows, all new code:
- **geom_mutation** M-D483a to e:
  - shallow freeze is enough for the text;
  - a getter counts as a value;
  - sealedNormal keeps any profile;
  - frozen-at-the-top is enough;
  - getters are allowed.
- **core-mutation** G-D483a to e:
  - no snapshot;
  - identity is always the same;
  - a getter counts as a value;
  - the snapshot copies nothing;
  - every chord is taken as the same.

`geom_mesh_stalekey` joined geom_mutation's file list, and `ghost-stalekey` joined core-mutation's.

**Two mutants re-pointed (their rule unchanged, their anchored line changed):**
