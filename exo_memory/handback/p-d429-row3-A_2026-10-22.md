## 5. Corrections and incidents

1. **My A/B waiter spun on the heavy-run lock for about two hours.**
   - Between 15:05Z and 17:00Z, `S\d429\waitab.js` ran ab.js **4,649 times**. Each try took and released both slots in about 0.2 s.
   - Cause: quiet.js counts a lock as "mine" only when its cmd matches `D421 sculpt-frame`. My D429 cmd did not match, so ab.js refused its own slot, and waitab retried on that error with no wait.
   - Other seats' hold() calls could at most have waited a fraction of a second per cycle. It was still churn on a shared lock.
   - Fixed: quiet.js now also matches `D429 row 3`; waitab retries only when the second-slot holder exits early, and then waits 30 s.
   - The spin's log is `S\d429\ab1-spin.txt`.
   - Lesson: a retry loop must never retry on an error it can't outwait; the ownership check was deterministic.
2. My covering-run script wrote its output file into the worktree (it changed directory there before writing a relative path). I moved it to scratch before committing; nothing extra was committed (`git status --short` showed only the untracked profiler scratch, now removed).
