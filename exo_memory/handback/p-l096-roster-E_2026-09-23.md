## 1 · THE CHANGE (`board-digest.js`)

- **The roster is read from `<data>/panes.json`**, using `readJson` and the **same `dataDir`** the hook already
  resolves (`CONSONANCE_DATA`, then `cfg.data_dir`, then `~/.consonance`). **A pane is added as silent if it is:**
  - a uuid (`UUID_RE`, the same filter the board rows pass);
  - not the reader itself (`sessionId`);
  - not already a talker today;
  - not already listed.
- **Names use the existing mapping, with no second one:** silent panes join the same naming loop as the talkers, so
  `letters.json` goes through `callsign()` (MAIN_SID → MAIN, then the NATO fallback). The column width includes them.
- **Silent rows come last, one line each**, with no asked, said or hands lines:
  `DELTA  0 exch · idle since launch`.
- **The empty-digest exit now needs both conditions:** no talkers AND no silent seats. With no roster, it exits exactly
  as before.
- **If there is no roster, or it doesn't parse as an array**, the output is unchanged from before (`[]` fallback, and
  `Array.isArray`). Tested four ways below.
