## Decisions (mine, each easy to flip)
- **The Extend field is not in the Ctrl+Z "un-apply" guard** (a typed grip not Extended is not put back by the first Ctrl+Z; it undoes the track). The guard works over the channel fields with their "at start" boxes, and grip is not a channel; say if you want it in.
- **Set grip applies to the road pieces of the selection and skips a flight** (a run across a jump is common) instead of refusing the run; a selection with no road at all is refused.
- **The colour scale is white at 100%, blue below, orange above** (so the default road reads as unchanged, and a track with no grip set shows all white); the key is drawn in the corner while the view is on.
- **The hover label adds grip only when it is not 100** (or the view is on), so no existing label changes.
