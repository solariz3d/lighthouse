## 3 · FOR B: install.js, not edited

1. **The output line the packet asked me to name:** `Undo: node jev/install.js --uninstall`. It assumes the parent-folder
   working directory. **The README now uses that directory throughout, so the line is right as it is.** No change needed.
2. **A REAL DEFECT FOUND WHILE RUNNING IT: backups are stamped to the SECOND and overwrite each other.** My case-A
   uninstall wrote `settings.json.bak-jev-20260924T000731Z`; my case-B install, in the same second, wrote a backup under
   **the same name**, replacing it. Three backup writes left two files. A person rarely runs both within a second, but a
   script or a test will, and **a backup that silently replaces another is lost data**. A fix is B's: add milliseconds or
   a counter, or open with `wx` and retry on EEXIST. The README says "`settings.json.bak-jev-<time>`" and makes no
   promise either way.
