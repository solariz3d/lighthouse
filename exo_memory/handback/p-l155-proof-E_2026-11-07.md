**What counts as the tiers MISSING a real red:**
- A red is **real** when a hand-back ruled it a defect or regression, or when the next commit changed code (not only the test) to clear it.
- A red is a **flake** when it passed alone, on the same tree, with no code change: a timing row under load, for example.
- Flakes are counted in their own column and do not fire the stop rule. They are reported anyway.
- **A pane-tier miss:** a real red that is not in T.
- **A landing-tier miss:** a real red in neither T nor F, on the machine that lands (L, where X does not run).
- **Default to refuted:**
  - if `test-touched.cjs` cannot list an old diff (it errors, or the diff is not recoverable), that red counts as NOT in T;
  - if I cannot tell real from flake, it counts as real.

**The falsifier (the packet's):**
