## 2. leftovers.js (fe247273)

`node consonance/tools/leftovers.js` (`--json`, `--downloads <dir>`, `--min-age <minutes>`, default 120). Read-only.
It sets itself to BelowNormal, and its two PowerShell children inherit that. A run takes about 6 s: one window read,
one control, one CIM process query and a few readdirs. Nothing disk-heavy.

**What it counts:**
- **Tab proxies:** top-level windows of class `Windows.Internal.Shell.TabProxyWindow` (EnumWindows), with their titles.
- **Worktrees:** the names in `<repo>/.git/worktrees`, for the Downloads repo and the Desktop repo.
  - For the Desktop repo that one readdir is all it reads. No git runs there.
- **`t180-*` not worktrees:** entries in Downloads named `t180-*` that are neither a repo's main checkout nor a
  registered worktree. A registered worktree is one whose own `.git` file points into `<repo>/.git/worktrees/<name>`,
  where that path exists.
  - A dangling `.git` file counts as a stray.
- **Fake roots:** `fake-*` at each drive root.
- **Our long-running processes:** older than `--min-age` minutes and named by one of our places:
  - a seat's `Temp\claude` folder;
  - lighthouse or its worktrees;
  - `Downloads\t180-*` or `lh-*`;
  - the seats' shell snapshots;
  - the scratch root;
  - `zz-headless-test`;
  - or a headless browser.
- **Left out as infrastructure:** `consonance.exe`, `claude.exe`, `msedgewebview2.exe`, the stick-waiter, world-sense
  and the shell's MCP servers.
