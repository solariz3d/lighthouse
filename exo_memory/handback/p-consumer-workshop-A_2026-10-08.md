## How I decided (the line I drew)
- **PRODUCT** = the thing a stranger's consumer runs, or a test of that thing's behaviour whose only missing piece is a fixture/file that is itself part of the product. It ships.
- **WORKSHOP** = the test reads **this room's record** (its journal, packets, plans, ASK inbox, git history, dated notes, run2 experiment rig) as its data. Standing rulings: `journal/2026-09-03.md` §2 and `loop/consumer_foundation_ruling_2026-09-06.md`: the SYSTEM ships, the RECORD does not. Declared, never deleted from source.
- A row inside a mostly-product file is declared **as a row**, not as the file: declaring the file would silently drop its other 34–56 behaviour rows from the consumer.
- **Anti-masking condition (applies to every WORKSHOP ruling below):** a declaration is only honest if the declared test/row is **green in the source tree**. All of them are (B: all green in source, JS 5 shared reds aside which are not in these rows; Rust 979/0). Please keep that checked in both directions (declared-but-passing-in-consumer is fine and should be reported, undeclared-and-red is a failure), the way `EXCLUDE` is.
