## 1 · THE FIX

`runClose` no longer takes `o.state || sync.stateDir()` straight into `path.join(STATE, '.git')`:
- the state dir is resolved once; a **throw** from `stateDir()` is caught **only to be printed** — its message rides in
  the refusal, so nothing is swallowed;
- a **null or blank** result is treated as undeclared;
- after the two existing data refusals, an undeclared state dir returns
  `NOT CLOSED — no state repo declared` · `Set state_dir in ~/.consonance.json, or set CONSONANCE_STATE. Nothing was
  prepared and nothing was sent.` · `stateDir() said: <reason>` when it threw · **exit code 2**, the same configuration
  code the missing-corpus refusal uses.

The order of the existing refusals is unchanged: no corpus → corpus missing → **(new) no state declared** → state not a
git repository.
