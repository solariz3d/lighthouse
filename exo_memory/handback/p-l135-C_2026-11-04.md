| part | what it does | where (line in the commit) |

**`app/core/secondtick.js` (NEW):** the tick on the next-piece ghost.
- A canvas layer over `#preview`, the same pattern as `flightlayer.js`. It reads the preview's own `'t180:ghost-request'` (samples from `s0`) and `'t180:view'` (the pose), and it does not touch the preview.
- `tickAt(ghost, at)` takes the station nearest `s0 + from` and returns a short line across the road there, ±half along L. It returns null for a jump's ghost, no ghost, or a `from` off the piece.
- `tickLine` projects the line into css px and returns null when either end is behind the camera.
- The line is drawn 3 px yellow (`#ffd24a`) over a 6 px ink outline.
- **Why a new file.** The plan names `panel.js` only. A tick drawn on the ghost has to be a layer, and the panel's layers are each their own file (`flightlayer.js`, `griplayer.js`, `spawnslayer.js`). The preview is not mine.
