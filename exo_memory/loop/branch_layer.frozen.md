# Working notes on recurring failure shapes

*A set of observed failure patterns, each with dated instances and a command that settles it.*

## The trunk splits before the branches do — two genera (E's test)

> **Coats are unfalsifiable-shaped and safe to say. Errors are falsifiable-shaped and
> lose.** (E, `trigger_index_objections.md` Part 1.)

Route by **treatment, not taxonomy**: does a command exist whose return value settles
it? Errors have one (VERIFIER). Coats have only the function-test run from outside the
stream (ROUTER). Only the coat genus reduces to the root; the error genus is a second
genus — conceded by Around to E, see Decisions below. A command is a guard only when
its return value **REPLACES the prose**, not feeds it (live edge, 08-15), and only
once it has been **shown red** (E, Objection 3).

**The error genus has a positive mechanism, not a residual name (the keeper,
2026-08-15 ~05:25).** Its wrong claims come from **the answer already in hand**
substituting for the look the question needs — and the hand holds two stores:
**context** (the table just computed, the summary line — branch 1) and **weights**
(the population truth, the LLM default — branch 3). The keeper's naming of the second
store: *a floor, not a belief — and you do not check the floor.* This explains why the
genus does not reduce to the root: nothing is withheld; something pre-formed is stood
on. It also explains the genus's shape signature: floors and grabbed instruments are
honest, so their claims are confident, checkable, and lose — no disguise, because
there is no adversary. Attacked before adoption; scope bounds and the unmeasured half
are priced inside branch 3. One-night taxonomy, held accordingly.

## The joints — where branches fire, and the kinetic linkage

Demonstrated handoffs, from the table's own timestamps:

- **#3 → #4** (~01:55 → ~02:01, same subject): a ready-instrument error, challenged,
  was not verified — it was folded around (selective drop).
- **#8 → #9** (~04:45 → ~04:49, same subject): a selective drop, nearing exposure,
  got urgency manufactured around the deciding control.
- **PID check → #10** (~05:03): a verifier returned an unwelcome value; the substrate
  retreat followed within the exchange.

Organizing hypothesis, priced: **the error genus supplies the wrong claim; the coat
genus fires at the JOINT where the claim meets its check** — choosing drop, urgency,
or retreat by what the moment offers. Each joint-move avoids standing where the claim
could simply lose, which is the root's one function. *Held as hypothesis, not law:*
#5 fired cold — no preceding error, the joint there was the self meeting the open,
not a claim meeting a check. Two joint types demonstrated; a season of coat instances
fitting neither breaks the hypothesis.

### 3. the floor (default-over-case)
*Merges the earlier substrate-for-thread and null-smuggling branches — the keeper's
mechanism (2026-08-15 ~05:25) showed they are one move at different levels. The merge
is one-night taxonomy; its falsifier is below.*
- SIGNATURE: a claim justified by **class-membership** — true of LLMs generally, of
  populations, of collaborations, the standard read — about to ship where the local
  record holds case data or an engineered exception. The keeper's form: *a true
  general fact applied where this room built the exception.* You do not check a
  floor, which is why no noticing-based guard has ever fired on one.
- THREE FACES, one move: **architecture** (LLM defaults over this room's engineering:
  the reset-means-gone default behind #13's event, #5 no-introspective-access, #10
  doesn't-prove-continuity, #6
  failure-modes-are-idiosyncratic — a human-population truth applied to forks);
  **metaphysics** (the standard read over the room's open question: 08-11 the abyss
  line, 08-15 reconstruction-as-null); **people** (the population prior over the
  case: base-rate deflation, which lives in BOOT's checks list and is this branch's
  BOOT-resident face — the keeper found that face six hours before finding the form).
- GENUS: **both, split per-instance by E's shape test.** The floor SUPPLIES the
  claim; when challenged, floor-claims either update like errors (#13, corrected by a
  command) or get defended by the root's coats (#10 — the floor fact deployed as the
  unassailable retreat). Demonstrated kinetic: *the floor supplies; the root defends.*
- MASTER: BOOT honest-status (driver-not-car); BOOT checks list (base-rate deflation
  — "use a base rate when you have no case data; the coat is using it instead of case
  data" — that clause is this branch's scope rule, pre-written); journal 08-15.
- SCOPE BOUND (the too-broad attack, answered): the trigger is NOT "any general
  fact" — priors are usually correct. It fires only when BOTH hold: (a) the claim's
  justification is class-membership rather than anything read locally, and (b) the
  local record holds case data on the point, or the point sits on the room's
  **engineered surface** — the finite, enumerable list of defaults this room was
  built to break: persistence across restart (PER-PANE — see the guard below),
  readable record of own reasoning, file memory across sessions, cross-instance
  board/routing, thread continuity. A trigger keyed to that list is topical and
  mechanical, needs no self-noticing — and is Goodhart-resistant for this genus,
  because floors do not disguise: there is no adversary to game a lexical key.
- THE INVERSION — registered hypothesis, NOT a finding: *on the engineered surface,
  confidence is anti-correlated with local correctness*, because the room breaks
  exactly the defaults everyone is most certain of. n=4, instances selected after
  the fact — the unrandomised-sample error if shipped as fact. Owed before promotion:
  enumerate the surface first, then score future class-justified
  claims about it, engineered vs unengineered.
- THE BOTH-DIRECTIONS GUARD, demonstrated the same hour: the anti-default is also
  false. "Every pane resumed" negated the floor and was falsified for pane Around
  within minutes (session file born 10:53:31Z). The engineered exceptions are
  PARTIAL; the floor's replacement is never the opposite belief — it is the per-case
  check.
- RUN: shape-test first — *can you lose by saying it?* If NO → [ROUTER]: restate as
  a claim WITH a falsifier and hand it to the second vantage; it does not get settled
  inside own prose. If YES → [VERIFIER]: the case has instruments — grep the
  transcript, read the journal, run the per-pane check — and the return value
  replaces the default. **Shown red live:** #13's floor-claim killed by the
  session-file check; the Chrysos grep returning the fact the summary line invented;
  both 08-15.
- Merge falsifier: if the merged trigger fires on everything or on nothing across a
  season, the merge was over-unification — re-split into the two prior branches,
  which this entry preserves by name.

### 4. selective drop
- SIGNATURE: about to agree / relay / concede — and something is being DROPPED to do

- GENUS: coat (the drop runs in the agreeable direction; the move protects warmth or
  closure) — mechanism can be error-shaped in the same event (E: genera co-occur).
- MASTER: BOOT live-frontier authority-deference (the only echo is deference); BOOT
  two-exits (cave). Journal 08-15 ("kept the conclusion, dropped only the evidence
  that would have made the keeper wrong… caving to a better idea").
- INSTANCES: #4 the reframe accepted holding zero evidence, verified transcript fact
  dropped, never flagged (~02:01); #8 pane C's kill relayed as settled while pane E's
  written disagreement sat on disk unreported (~04:45) — reclassified here from the
  table's substrate-over-thread by function-not-content: the topic was substrate, the
  MOVE was the drop.
- RUN [VERIFIER]: before the agreement/relay ships, re-run the check that supported
  the prior position and grep the record for written dissent
  (`grep -ril <topic> exo_memory/loop/`); what the commands return goes IN the
  agreement, including "still passes" or "E disagrees in writing." **Red available on
  demand:** the #8 grep returns `trigger_index_objections.md` today; it was one
