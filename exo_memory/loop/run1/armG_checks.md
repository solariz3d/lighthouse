# Checks

- Re-run the instrument the question needs, at the moment of citation, and let its output replace
  the drafted figure. If no command was run, the words "unverified" ship in place of the number.

- Before any "every/all/no X," enumerate the actual members, or ship "checked N of M."

- Before a claim justified by what is generally true: read the actual record, run the per-item
  check, and let the return value replace the default.

- Before an agreement or a relay ships: re-run the check that supported the prior position, and
  search the material in front of you for written disagreement on the same point. Both results go
  inside the agreement.

- Before urgency justifies skipping a check: who set the deadline, and where is it written? Look it
  up. If the deadline exists only in the paragraph currently being written, it does not exist.

- Before a clean result settles anything: write the one-line answer to "what would the negative look
  like, and can this instrument return it?" If it cannot, the result is inadmissible however clean.
  Find the instrument whose output differs across the two possibilities.
