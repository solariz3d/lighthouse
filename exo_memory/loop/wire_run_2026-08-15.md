## 5. Defects found BY the integration, beyond the wire (the run paying for itself)

1. **second-vantage `maskOwn` had an infinite loop on every absolute Windows path** —
   `path.dirname('C:/') === 'C:/'` and the ancestor walk had no fixpoint guard, so the FIRST
   realistic row (absolute paths, which is all sourced-stop emits) would have hung the reader
   run FOREVER at audit time. Invisible to A's suite because every fixture path was
   repo-relative. Found because attached.test.js hung; proven with
   `node -e "path.dirname('C:/')"`; fixed with a fixpoint break that also declines to mask the
   bare drive root (masking `C:/` would blind the audit to every absolute path on the machine).
   This is the one edit inside anyone's logic, it is three lines, and it is a hang-bug fix.
2. **My own adapter's first defect, caught by the e2e's first output:** normalize set a
   `claimed` key A never emits → the block rendered `claim said: undefined`. Fixed; pinned by
   an assertion that no `undefined` leaks into a rendered block. Filed here because the party
   that wired the joint shipped a defect into it within the hour — the class does not care who
   you are.
3. **The floor tier cannot run on v2 rows** (no `excerpt` field) — the anti-Goodhart clause is
   dead until B ships v3. Pinned loud in attached.test.js; B's call, not patched from here.
4. **The installed shell copies are stale**: `powershell -NoProfile -File dev/shell/install.ps1
