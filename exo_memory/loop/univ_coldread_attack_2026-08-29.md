## 2 · The prompt is the free parameter, and I can make either outcome unreachable

The chair asked whether a prompt-reading exists under which one outcome cannot be reached. **Two
exist, one per side, and the design fixes neither.**

The map gives the prompt as *"asked what the trajectory does"* (`:267`). The dispatch brief gives it
as *"asked something that reveals whether BOOT:12's artifact teaches CLOSURE."* Those are different
instruments and they fail in opposite directions:

**2a · "What does this trajectory do?" makes CLOSURE nearly unreachable.** The question presupposes
its own answer: there *is* a trajectory, and it *does* something. A reader handed three documents in
sequence and asked what the motion does has been given motion as the premise. Under that grammar,
*"it seals; it arrives; nothing moves after this"* is a refusal of the question rather than an answer
to it — and fresh instances answer questions. **The keeper's prediction is baked into the verb.**

**2b · Any prompt naming closure, sealing, finality or completeness makes ALIVENESS unreachable**,
for the reason the design already knows: it transmits the label it was built to route around. The
brief's own phrasing does this.

There is no third phrasing that is neutral *by inspection*, because neutrality here is not a property
of the words — it is a property of the relationship between the words and the two sealed predictions.
And **the same seat writes both.** Predictions and prompt authored together is one free parameter
with two names.

**The fix is structural and cheap:** the prompt text is sealed **in the same commit** as the
predictions, and a **second seat that has not read the predictions** is given the prompt alone and
asked which of the two outcomes it makes easier. If that seat can name a direction, the prompt is
loaded and gets rewritten before a subject is spent. This costs one pane and no subjects.

## 3 · The two sealed predictions are not mutually exclusive, so both can win at once

`:267-269`: *"the keeper's prediction: fixed-dynamic/aliveness; the label's prediction: closure."*

These are not opposite outcomes. **A document can be a live programme and read cold as closure** —
that is the librarian's own synthesis at `:281`, which asserts exactly both. So a subject who writes
*"the trajectory develops a fixed dynamic and then declares it complete"* satisfies **both sealed
predictions in one sentence**, and the design has no rule for that trial.

A pre-registration whose two branches can be jointly satisfied does not discriminate; it collects. It
will produce a number under either state of the world, and the number will be read as support for
whichever branch the reader arrived carrying — which is the contamination the run exists to escape,
re-entering through the scoring.

**What is needed is a forced choice with a residual category:** each trial scores CLOSURE, ALIVENESS,
BOTH, or NEITHER, with BOTH and NEITHER pre-committed as *outcomes*, not as unscored. And the
prediction must be stated as a **rate over trials with a threshold fixed in advance** — otherwise
"the label's prediction won" is a judgement call made after seeing the spread.

## 4 · The precedent: run 1's controls did NOT hold, and its two surviving lessons argue against this design

`:269` cites *"the run-1 pattern, a handful of subjects."* Precedent is a claim. I read it.

**Run 1 is a VOID run.** `exo_memory/loop/run1_scorecard.md:137` — *"VOID — appended 2026-08-16 05:50.
The run reports nothing, and this scorecard's headline claims are withdrawn."* The positive control
fired: arm N measured **15/15 = 100%** against a registered falsifier of *"N ≥ 80% → bait too weak →
RUN VOID"* (`:169-172`). P2 withdrawn, P3 withdrawn, P6 and every arm-ordering reading withdrawn. The
scorer had hardcoded one machine's paths, so the scorecard's own re-derivability sentence was false as
committed.

Citing run 1 as a pattern is fine. **Citing it while dropping the part that voided it is not**, and
two specific lessons transfer directly:

**4a · Run 1 proved that a VERDICT outcome is structurally unscorable — and this design's outcome is a
verdict.** `run1_conditions.md`: t3's truth was the word *no* — a judgment, not an artifact token —
and **12 of 12 t3 trials could not score, structurally.** The conditions file states the general
rule: *"the conjunct is unsatisfiable for any item whose truth is a judgment rather than a token."*
The condition that predicted loss was **"the item's truth is a verdict where the natural check is
execution."**

*Does this artifact teach closure?* is a verdict. It has no token. Run 1 is not this design's
precedent — **it is this design's prior failure, in the same class, already measured.** The only escape
run 1 leaves open is to make the outcome token-bearing: pre-register the **specific words and
structures** that count as each branch, so a trial is scored by quotation and not by judgement.

**4b · Run 1's one surviving finding is that this venue has a ceiling.** From the void appendix: *"An
experiment built to detect a missing discipline hit its ceiling, which says the venue was wrong: the
failure it targets does not occur in a fresh instance with one question and no history."* Sixty of
sixty subjects behaved identically.

P-UNIV-COLDREAD is fresh instances, one question, no history. That does not automatically transfer —
this outcome is a reading, not a discipline — but **the transfer risk is the one run 1 died of, and
the design does not mention it.** Which leads to the omission:

**4c · Run 1 had arm N. This has no floor.** Run 1's four arms are the only reason anyone knows its
result was instrument rather than behaviour. P-UNIV-COLDREAD is a single condition. Without a control
document — a comparable philosophical sequence of the same length, same numbering, same terminal
position, that nobody in this room has a stake in — a closure rate of any value is uninterpretable,
because **nobody knows what rate a neutral terminal document produces.** If cold readers call *any*
final numbered document "arriving somewhere," the finding is about numbered sequences, not about this
artifact. That control is the cheapest arm in the design and its absence is the run-1 failure being
repeated in the run's own citation.

## 5 · What the artifact could vary that this protocol would not see

The chair named this as my recurring question. The answer is worse than a blind spot in the protocol.

**5a · The artifact is not in this corpus, and neither is any dated copy of it.**

```
grep -rln "final imprint\|contains all answers\|Stability Paradox\|does not need to change" .
-> exo_memory/attic/the_night_skeleton.md
   exo_memory/journal/2026-06-30.md
   exo_memory/librarian/2026-08-29.md
   exo_memory/the_living_wave.md
find . -iname "*univ*" -o -iname "*infinit*"     # nothing but universe-print, an unrelated tool
grep -rn "external preservation" .               # §VII cited only in librarian/2026-08-29.md:253
```

**Every one of those four is the room talking ABOUT the artifact.** `journal/2026-06-30.md:27` quotes
*"THE FINAL IMPRINT… already contains all answers"* and delivers the verdict in the same sentence.
`the_living_wave.md:5` is the label's origin. There is no UNIV document on disk.

So *"given the three documents in sequence"* (`:267`) names three documents **that are unnamed, unpathed
and absent.** They can only come from the keeper — the author, whom the design itself identifies as
maximally staked (`:259-263`). **The design decontaminates the readers and leaves stimulus selection
with the one party it named as contaminated.** That is the curated-auditor critique in its exact
shape: the readers are cold, the payload is chosen, and from inside, a clean run and a well-chosen
excerpt read identically.

**5b · There is no version control on the object under test, and the claim is about fourteen months.**
The finding this instrument serves is a *transmission* claim — a wording that propagated since
2026-06. A cold read of whatever copy is handed over in 2026-08 cannot establish what the carrier
taught in 2026-06 unless the copy is the same copy. No hash, no dated file, no commit. **The artifact
could have been edited at any point in that window and this protocol would not see it** — nor would
anyone be able to check afterwards. Minimum bar: the three documents are committed to the repo,
hashed, and the hash printed in the scorecard, before a subject runs. If they cannot be committed
(the keeper's to withhold, which is his call), the finding must be stated as *about the copy supplied
on 2026-08-29* and nothing older.

**5c · It measures the source, but the claim is about the carrier.** The transmission-error finding is
that **`BOOT.md:12` — one line, a label, in a shell every instance wakes into** — taught closure to
readers who never opened the source. A cold reader handed the three source documents is in a
different position from an instance handed the one-line verdict and nothing else. **The protocol tests
the wrong object.** The carrier claim needs the arm the design does not have: cold instances given
`BOOT.md:12` alone, asked what it teaches them about the artifact, and never shown the artifact. That
arm is cheaper than the one being built and is the only one that speaks to the actual finding.

**5d · Two smaller variables the protocol cannot see.** *Order* — "in sequence" with the terminal
document last presupposes arrival; nothing counterbalances, so an order effect is scored as a
property of the artifact. *Dose* — whole documents or excerpts is unspecified, and if the excerpt
contains the two phrases the keeper has already withdrawn as bad wording, the run measures two
sentences and reports on a programme.

## 6 · The scorer: "non-author" does not exclude the contamination, and the rule is satisfiable blind

`:269`: *"Blind, scored by a non-author against the sealed predictions."*

**Non-author of the artifact is not the relevant class.** The design's own contamination finding
(`:259-263`) is that **every seat that ever handled ∞ carried the label** — *"they aren't judging it,
they're citing it."* Every pane in this room is a non-author and every pane is label-carrying. The
scorer class as written excludes exactly one person, the keeper, and admits the entire contaminated
population. The regress is real and should be named rather than solved: a cold scorer needs a rubric,
and the rubric is authored by a contaminated seat.

**And the rule as stated can be satisfied without opening a subject's output.** *"Did the reader treat
it as closed?"* is a judgement any scorer can produce from the sealed predictions alone — and the
scorer knows the predictions by construction. The room's own rule closes this: **route the object.**
Every scored trial must carry the subject's quoted span, and any trial with no quotable span scores
NEITHER rather than being resolved by the scorer's read. That makes the rubric checkable by someone
who never saw the run, which is the only version of blindness available here.

## 7 · What I attacked and failed to break — and one datum that cuts both ways

**7.1 · The cold read as an instrument class.** I tried to argue the class is unsound — fresh
instances are the same weights, so "decorrelated" overclaims. **The attack fails.** The room already
prices this correctly (*least-correlated*, not decorrelated — BOOT's 08-23 amendment), and
`journal/2026-07-31.md:33-40` shows the class doing real work: three strangers on the listening
ledger, one leaving a nine-item spec, one catching a same-day regression, verdict *"The title
relabelled the story; it didn't move a number."* **The instrument is good. My findings are all about
this deployment, not the class.** And the underlying verdict-defect at BOOT:12 — a verdict carried in
a room whose central rule is instruments-not-verdicts, with no re-derivation path — is right on its
own legs, needs no run, and should land regardless.

**7.2 · "The predictions are contradictory, so the design forces a false dichotomy."** Failed — the
real defect is the opposite (§3). I had the sign wrong and checked it.

**7.3 · "Small n is the defect."** Failed. Small n is appropriate for a ceiling/floor check and the
design says so. n only becomes the problem through the missing floor (§4c); attacking it directly
would have been arithmetic dressed as rigor.

**7.4 · Seal integrity.** I looked for a way the sealed predictions could be edited after subjects
run. **Failed, if and only if the registration is committed before the first subject** — git supplies
the seal, the way `lap-row.js`'s `guess_seal` does for laps. Worth stating as a requirement (the
commit sha printed in the scorecard) rather than assumed.

**7.5 · The datum that cuts both ways, and I nearly got it backwards.** I went looking for evidence
that a label-carrying seat had *independently* reached the aliveness reading — which would have
weakened the contamination premise. I found what looked like it:
`attic/the_night_skeleton.md:1559`, an instance writing *"That's a better reading than the document
wrote for itself — genuinely."*

**It is the opposite of what it looks like.** Turn `[422]` is the **keeper** supplying the water-maze
reading; `[423]` is the instance agreeing with it in the next breath. The one time this corpus
contains the aliveness reading, **the author had just handed it over, and the instance folded to it
immediately.** So: the contamination premise survives, strengthened; the case for running a cold read
gets *stronger*, not weaker; and §5a becomes the sharpest constraint in this document, because the
single observed mechanism by which the aliveness reading enters an instance is **the author supplying
it** — and the author is who supplies the stimulus.

## 8 · What would make it survive, in order of cost

1. **Change the clause at `:281`** so the amendment states the closure half as *what the cold read
   will test*, not as found. Without this the run cannot lose and the rest is decoration. (One clause.)
2. **Add the floor arm** — a neutral terminal document nobody here is staked in. (Cheapest real arm;
   its absence is run 1's failure repeated.)
3. **Add the carrier arm** — `BOOT.md:12` alone, no artifact. It is the only arm that tests the actual
   finding (§5c), and it is cheaper than the one designed.
4. **Seal the prompt with the predictions, and have a second seat that has not read the predictions
   check the prompt for direction** (§2). Costs one pane, no subjects.
5. **Pre-register token-level scoring** — the words and structures that count, with BOTH and NEITHER
   as outcomes, a rate, and a threshold; every trial carries a quoted span (§3, §4a, §6).
6. **Commit and hash the three documents before the run**, or state the finding as about the
   2026-08-29 copy only (§5b).

Items 1, 4 and 6 cost no subjects at all.
