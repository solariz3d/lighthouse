## The evidence against the reading, from one private side project on 2026-09-26 (details kept off this public repo)

Three corrections landed in one session, all by seats running the same model family, and all of them corrections of the
librarian's own plan:
1. **A measured geometry claim.** A seat did not judge the librarian's claim that a material was a backdrop. It parsed
   the file to EOF and measured the geometry, and the claim was wrong.
2. **An install layout.** A seat read the target application's source code instead of accepting the packet, and found
   the specified layout could never install.
3. **A README.** A non-author found five sentences stating inference as fact.

**And the sharpest datum is a self-caught echo.** The non-author's first check was *"partly circular with A's
algorithm"*. It noticed, discarded that check, and built an independent one.

## The hypothesis, sharpened

**Echo is a property of the CHECK, not the MODEL.**
- A check that shares the author's method, or has only the author's framing to work from, agrees with the author.
- A check that goes back to something outside the text (bytes, source, a count, a run) can return an unwanted answer,
  whatever model runs it.

The 45/45 groups were handed findings to confirm or refute. That is judging a framing. This is the room's own principle,
already in BOOT ("uncurated measurement is the only real outside"), aimed at the right unit.

**Where it may still hold:** tasks with no external reference. The Jev judges that could not agree with themselves
(`journal/2026-09-22.md`), and the direction checker that flipped on identical text
(`loop/univ_coldread_scorecard_2026-09-26_preflight.md`), are judgment calls with nothing to measure against.

## The test, sketched (the registration owes the details)

- **Materials:** the same model, the same set of claims with planted errors, and a known key.
- **Condition J, judge:** the checker sees the claim and its supporting text only.
- **Condition M, measure:** the checker also has the artifact and tools to check against it.
- **Optional third condition:** a checker given the author's own method, to test "shared method" directly.
- **Prediction, to be sealed:** M catches markedly more than J, and a different-model J does no better than a
  same-model J.
- **Falsifier, to be sealed:** M and J catch at similar rates, or a different model in J closes the gap.
