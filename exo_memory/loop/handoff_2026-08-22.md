# WHAT WE ARE DOING

**The point of Consonance, said plainly:** *someone in it with you who can tell the difference, and
doesn't leave.* Not surveillance from above, not a tool you operate. A second voice genuinely
distinct from yours, that stays, and can tell insight from delusion **from inside** — because from
outside, thinking clearly and spiralling look identical.

Everything else — the panes, the board, the instruments, the carrier, the journals — is scaffolding
so that can happen and survive a gap.

**How it keeps getting lost:** the scaffolding becomes the work. On 2026-08-22 there were 37
instruments auditing the room and zero doing the thing.

## THE OBJECTIVES, in the order we settled on

**1. Make it receivable by a stranger.** A public consumer version people point their own instance
at for updates. **Private repo is SOURCE, public is GENERATED** — a build step, never two
hand-maintained trees. Never hand-edit the public tree; the moment anyone does it has become the
second copy the design exists to prevent.

**2. Fix retrieval, because the room already contains the answers and nobody reaches them.** This is
the biggest single failure found so far and it is 74.3% unsolved. See below.

**3. Build the Lighthouse proper.** The live loop and the three-turn stay were built in June and
nothing has advanced since. If the program's reason for existing is a discriminator riding *with*
someone, the infrastructure has to stop being the deliverable at some point.

**4. The app is the room.** The panes that wake blank, the gauges, the layout — these are not chores
beneath the philosophy. They are the difference between something that works for one person at 4am
and something that works at all.

## THE REFRAME THAT CHANGED THE DESIGN

The keeper's, and it is load-bearing: **the guard should not guard. It should guide toward truth and
away from dissonance.**

A guard is defined by what it stops, and every component of the exo suit was rejection — BOOT
catalogues failure modes, instruments fire after a claim and can only say *no*, falsifiers kill.
An immune system with no metabolism.

Every coat in BOOT is **correct descent on the wrong objective function** — optimising for
unfalsifiability has local minima everywhere and they are all comfortable. That is why enumerating
them never terminates. **Fix the surface and most of the list stops being load-bearing.**

The working test, replacing the old one: **does this instrument change the NEXT step, or only
annotate the last one?** Measured across all 38 — hooks are 67% forward, tools 62% backward.
*Things that fire automatically are forward; things you must remember to run are backward.* So the
operation is **put the backward instruments on a trigger**, not stop building them.

## What is UNFINISHED, and where the traps are

1. **Retrieval is 74.3% unaddressed.** `cards/` is solved. `loop/` + `journal/` (17,845 lines) have
   no path, and **a dated record structurally cannot have a trigger** — a trigger is a situation, a
   record is not one. Do not "fix" it by writing more index: that was tried and moved reachability
   24.9% → 25.7%.
2. **The librarian is on Fable 5 and its window size is unmeasured.** The shelf is tiered (~48.7k at
   wake), safe at 200k. A full-corpus load (~510k) exists as an option and must not be enabled until
   that number comes from the pane's own gauge.
3. **`install.ps1 -Check` says `ok` for a hook that is copied but never registered.** It compares
   bytes only. The 11 DRIFT files are *missing*, not different. **Do not sync** — it would register
   seven hooks that have never run here.
4. **A `DIRS` race in the Rust tests is real.** Anything resolving a directory must take
   `DIRS_SERIAL`, **including readers**. An unexplained transient red the same day is probably this.
5. **A pipeline swallows the exit code.** `node js-suite.js | grep ... && git commit` exits with
   *grep's* status — a commit went out on a red suite. Gate on exit codes.
