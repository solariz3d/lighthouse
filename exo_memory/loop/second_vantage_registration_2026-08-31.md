## 3 · The gated form — REGISTERED, not built, with its precondition named

**3.1 The one difference.** B §3.2 killed the printing cue for the turn-boundary rule because
`PreToolUse` fires *after* the dispatch text is composed and can only comment on it. PREREAD is a
different shape: the thing being guarded is not the composition of the dispatch but **whether the object
it cites has been read by someone else** — a fact about the world, checkable at `PreToolUse`, before the
dispatch lands. The existing gate already extracts the sha (`findCitation`), already stops the verb, and
already showed the only before/after this room has for any cue: **115/178 = 64.6% → 75/78 = 96.2%**
(B §1; one subject, a rising pre-trend, *associated* not *caused*). PREREAD-GATE is one more clause at the
same event, not a new hook.

**3.2 The design, in the words a builder would need — and none of it exists.**

- **Trigger.** In `dispatch-gate.js`'s `main()`, after `findCitation` returns a sha: if
  `git show --name-only <sha>` touches `exo_memory/loop/*registration*` or `exo_memory/librarian/*.md`,
  look for a **receipt**.
- **Receipt.** A board row (`C:\Consonance\data\board.jsonl`) whose text matches
  `^reviewed <sha7+> · (\d+) changes` — posted with `post_board`, so **attribution is the mount, not the
  tag** (the control plane's own rule), and "non-author" is checkable: the receipt's mount must differ
  from the seat named in the commit body's attribution line (the 08-26 amendment; all commits are
  authored `solariz3d`, so the body is the only author surface — a commit with no seat line is reported
  as such, not silently passed). Verified, not assumed: board rows carry the mount as a `pane` uuid
  field (`tail -1 C:/Consonance/data/board.jsonl` → `{"pane":"…","role":"assistant","text":…}`), so the
  reader's identity is readable by the gate without trusting the tag. Zero receipts today (`grep -c "reviewed [0-9a-f]" C:/Consonance/data/board.jsonl` → 0).
- **Decision.** No receipt → `permissionDecision:"ask"` with a question that names the sha and the
  missing reader, in the gate's existing two-channel form (the `systemMessage` carries the same words).
  Receipt present → allow, and record `reviewed_by` on the gate's ledger row. **Fails OPEN**, like every
  clause in that file. `[interrupt]` stays exempt.
- **Ledger.** No schema change to `lap-row.js`: a chain stage `reviewed` — written by the reader on
  completion, `--holder` naming the chair as next, note `sha · N changes` — is the packet's `reviewed_by`
  in the shape the ledger already has (a baton, not a status). `--report` gains one line per lap:
  reviewed stages / registration dispatches. That line is a build, and the report's blindness to correction
  rows (the librarian's ~02:10 item 1) is a separate defect this does not fix.
- **Reader-side trigger, so the hop is not the chair's memory.** The read is fired by the **commit**, not by

## 9 · Reproduction — the un-ferried count by path class

Read-only; parses git and the ferry ledger; writes nothing. Not installed into `consonance/tools/` (a
one-night probe is not an instrument — E's precedent, 08-25). Save as `regferry.js`, run from the repo root.

```js
const {execSync}=require('child_process'); const fs=require('fs');
const ledger=fs.readFileSync('C:/Consonance/data/ferry.jsonl','utf8').split(/\r?\n/).filter(Boolean)
  .map(l=>{try{return JSON.parse(l)}catch{return null}}).filter(Boolean);
const shas=new Set(ledger.map(r=>r.sha).filter(s=>s&&s.length>=7));   // ferry.js MIN_SHA
function count(glob,label){                                            // NO quotes around glob: cmd.exe
  const out=execSync(`git log --since=2026-08-10T11:04 --format=%H -- ${glob}`,{encoding:'utf8'})
    .split(/\r?\n/).filter(Boolean);
  let f=0; for(const h of out) if([...shas].some(s=>h.startsWith(s))) f++;
  console.log(`${label}: commits ${out.length} ferried ${f} missed ${out.length-f} miss ${(100*(out.length-f)/Math.max(1,out.length)).toFixed(1)}%`);
}
count('exo_memory/loop/*registration*','registrations');
count('exo_memory/librarian/*.md','librarian notes');
count('exo_memory/loop/*registration* exo_memory/librarian/*.md','either');
```
