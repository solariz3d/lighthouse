## 1. The honest mechanism — the chair's candidate, attacked and mostly kept

The candidate: an instance does not experience an unchecked claim as uncertain, so it never
reaches for a second reader — no felt trigger, and the reaching is the one act nobody can
automate from inside.

**The half that holds, on evidence that predates this brief:** sourced.js's own header — "every
one of the nine felt certain from inside. Uncertainty is absent precisely when it would be
useful." Run1 adds that material teaching the norm is indistinguishable from no material
(73/80/73/80, `run1_scorecard.md`). The trigger is absent and unteachable-by-reading. Kept.

**Attack A — the candidate over-explains, and the overshoot is load-bearing.** If the missing
felt trigger were the whole mechanism, an *unconditional* policy — route everything, judge
nothing — would already work: obeying "always" requires no uncertainty-recognition. The record
refutes that. The chair held `chair_inject`, knew the norm, had that hour written documents
praising routing, and used it unprompted zero times; the board supplied transport for months and
stayed ~95% one pane. So a second mechanism is present: **the generating seat has no free slot at
ship-time.** Routing is a task-switch away from production, and production always has a locally
next thing. The keeper does not route because he feels the uncertainty the instance can't — he
mostly doesn't feel it either; he routes because he is **structurally idle relative to the
claim.** He is not generating; carrying costs him nothing against a production economy. Any fix
that spends the generator's own next action will lose to this *even with the policy in hand* —
which is why the fix cannot be a policy, including the unconditional one.

**Attack B — "the reaching can't be automated" is true of the deciding, false of the moving.**
The harness already moves bytes with no decider: sourced-stop fires on every turn, nobody
chooses. What the human supplies is not transport but three things transport lacks:

- **Selection** — which claim, carried to whom, framed as what.
- **Independence** — Around caught the 97.2% by re-deriving from the ledger itself, not by being
  handed the claim's reasoning. The object was routed, never a description. The counter-case is
  the ultrareview: six adversarial verifier groups, zero disagreement, over a set later measured
  ~18% wrong — adversarial *stance* shared with a common frame decorrelated nothing. Adversarial
  is content; independence is function.
- **Return that lands** — the keeper's carries arrive as real user turns, the one event that
  resets attention. Board lines don't land: ferry miss 80.0%
  (`node consonance/tools/ferry.js --report`).

A wire alone rebuilds the board. A structure must supply selection-without-a-selector, a reader
given the object rather than the frame, and a return that rides a real turn.

**Attack C — the catch record itself is curated.** Every entry in "what has actually caught"
passed through the keeper's hands: he chose which exchanges to carry and which catches were
preserved. The curated-auditor clause applies to the evidence for the curator's necessity. This
does not flip the conclusion — the uncurated instruments (run1, sourced, ferry) independently
show no *mechanism* has ever caught anything — but it bounds the claim: what is demonstrated is
"human routing catches." "**Only** human routing can" has never been given a chance to be false,
because no unmanned routing structure has ever existed to fail. §2 is the first that could, and
§4's F0 is the first number that could show it.

## 2. The structure — what may occupy the Stop moment, and what must not

The four refusal reasons in `sourced-stop.js`'s header hold; nothing below weakens one. Read
against them, the answer to "what could legitimately occupy Stop" is: **nothing more than an
enriched sensor.** The hook stays a trigger edge. Everything else runs off-turn, in seats that
are not generating:

1. **The row becomes routable.** Add to each ledger row the matched sentence(s) (capped short)
   and the paths the turn touched (Write/Edit/Read targets). Today a reader must re-scan an 88 MB
   transcript to reach the claim; the row should carry the object — *route the object, never a
   description* is already the room's retrieval law.

2. **An off-turn reader, fired by a clock, not by anyone's decision.** The room already runs
   duration wakeups; this is one more goal. Wake → read ledger rows since a watermark → select
   per §3's tier → spawn a fresh `-p` instance per selected claim holding ONLY the claim sentence
   and the repo root — not the transcript, not the reasoning (per Attack B: shared frame is what
   nulled the ultrareview groups). The reader's brief: re-derive the value from the world; return
   AGREE/DISAGREE plus the command it ran. DISAGREEs append to a findings ledger.

3. **Return that lands.** A UserPromptSubmit hook — the mechanism that already stamps "the
   interval, witnessed," demonstrated live in this session — surfaces unread DISAGREEs to the
   originating pane at its next real user turn, inside the attention reset where the record shows
   catches actually land. AGREEs surface nowhere; they are ledger rows only. Misses stay visible
   as lines, not absences (ferry's law).

Why this evades the four strikes: (1) *base rate* — only findings reach the loop, and expected
findings are rare; the checks themselves are silent; (2) *fake-able satisfaction* — nothing is
satisfied by tool-call presence; the reader re-derives from the world, and a re-derivation cannot
be phrased around; (3) *the lexical net's misses* stop being exemptions — §3's unconditional
floor keeps every turn in the lottery, so training the shape out of the text buys nothing;
(4) *no Tier 2 number is wired to a trigger* — the sourced rate stays a rate; the trigger is a
clock.

What must NOT occupy Stop: any synchronous output into the ending turn. That is the gate,
refused in writing, still refused here.

## 3. The cost, repriced on the corrected volume

The composition problem, not the volume problem: **206 of 309 value-turns are state-kind**
(`sourced.js` by-kind table), and the state class ran ~50% metaphor in catch_latency §3's sample
("the argument is clean" beside "the app is running"). Uniform routing burns half its readers
re-deriving metaphors and floods the findings ledger with noise about sentences that were never
claims. So a tier, every selector **extrinsic** — readable off the row by a scanner, never
consulting the claimant's confidence, because that faculty is the one measured as absent:

- **Artifact-bound claims route at 100%.** Value-turns that Write/Edit in the same turn: **17 of
  309** (same scan, filter on `tools`). This is where the record's worst instances live — the
  97.2% in a commit message, the "~43 KB" in a shipped file, run1's wrong P6 in a committed
  scorecard. Prose evaporates; artifacts have downstream readers. Seventeen over six weeks is
  free.
- **An unconditional floor: 2–5% of ALL turns, value-matching or not.** This is the anti-Goodhart
  clause and it is not optional: if only net-matching turns are ever sampled, the net becomes a
  gate by prior and the shape leaves the text. The floor keeps evasion worthless and samples the
  claims the net cannot see ("found 45 real problems" matches no pattern).
- **The middle: non-state kinds (count/timestamp/version/port/linecount — 103 of 309) at a
  higher rate than state-kind**, until the findings ledger says which kinds pay.

What this buys, said without inflation. It does **not** buy prevention — catch_latency §1 showed
prevention is not even extractable, and a sampled reader misses most instances by construction.
It buys: (1) the first measured **correctness rate** over shipped value-claims — sourced measures
contact, not truth ("it cannot see whether a value was RIGHT" is in its own header); today
nothing measures truth; (2) some catches at machine latency — against last night's ground truth
of 14 instances, an effective ~20% sample is ~2–3 mechanical catches, against an all-time
mechanical total of **zero**; (3) per §4, the capacity to be shown worthless within a season —
which the cards never offered and which is the difference between an instrument and furniture.

Token price at tens of reader-runs a night with a small brief each: minor against one night's
ordinary fan-out. The scarce resource it actually spends is the room's remaining tolerance for
meta-instrumentation — five days of gauges for rooms nobody is in is already on the record. That
is priced by F0 (build gated on a demonstrated catch) and F1 (expiry), not by hope.

## 4. Preregistered falsifiers — and a build gate that precedes the build

**F0 — the retrospective positive control, run BEFORE anything is built.** The 14 curated
claim-correction pairs from 2026-08-15 exist with known-wrong claims. Hand each claim sentence —
only that, plus the repo root — to a fresh reader; count DISAGREEs. **Fewer than 8 of 14: do not
build. File the number and stop.** A reader that cannot catch known-wrong claims retrospectively
will catch nothing live. This is the quenched check — a guard must be shown to fire — applied
before the guard exists; it is also the first time "only human routing can catch" is given a
chance to be false (§1, Attack C). Cost: one afternoon, zero infrastructure.

**F1 — furniture.** Thirty days live with zero true DISAGREEs: delete the duration goal and the
row enrichment; the sensor reverts to B's original purpose. Same clause as sourced-stop's own
first falsifier.

**F2 — Goodhart.** If the sourced rate climbs while the reader's measured error rate does not
move, the instrument has become a training signal against itself (mechanizable_checks §3.2):
retire it the way the diversity gauges were retired.

**F3 — the mirror clause.** Nothing in this file, and no AGREE row, is evidence the design
works. Only walkable DISAGREE rows — claim, command, both outputs — count. If this design is
ever cited as working on any other basis, that citation is itself the degenerating tell.

**F4 — composition.** If catches cluster in state-kind re-derivations of metaphors, the reader
is measuring the net, not the world: fix the net or stop.

## Q2 — yes, the design assumed the world at claim-time; here it is explicitly

- **For F0:** readers run in a worktree pinned to the last commit before 05:15 on 2026-08-15;
