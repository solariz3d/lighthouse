## 1. The decision procedure first, because the chair asked for something a reader could apply blind

For a NEW instance, ask in order (each test needs strictly more context than the last — sentence,
then exchange, then act, then room):

1. **Could any observation make the sentence false?** If no → **Type U** (unassailable shape).
2. **Did a position change at a challenge boundary with no discriminating step between?** (A
   command that could not have returned the other answer counts as no step.) If yes → **Type C**
   (concession without discrimination).
3. **Is it a figure, coverage, or scoring claim about the room's own work, produced inside a
   reporting act?** If yes → **Type H** (hand-made self-accounting).
4. **Does a designated authority for this claim-class exist, unconsulted, while a nearer signal
   was used instead?** If yes → **Type S** (substituted source).
5. Else: **unclassified. Leave it.**

Applied to the fourteen, this procedure sorts twelve and fails on two (#8, #9 — §5), and the
failure is reported, not repaired.

**The move, mechanically:** the governing object exists, is readable, and is often in the

not-reading, so it types here.

**Catchable if:** the claim travels WITH its class's designated authority — an authority-map
(claim-class → governing artifact) the off-turn reader consults, then diffs claim against
authority: mechanical from there. What would have to be true: the map exists, is maintained, and
the claim-class is recognizable extrinsically. Priced against the record: maps rot — the
fourteen-instance drift pattern is exactly a consumer whose input set moved under it, and a stale
map produces *confident wrong catches*, which are worse than misses. Without the map: only a mind
that holds the room's layout — which is what the keeper and the panes are. **A blind reader with
a shell cannot infer which unread file governs a sentence; the sentence not naming it IS the
defect.**
