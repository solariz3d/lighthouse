## WHERE THE PRINT AND THE SOURCE DISAGREE — three rig findings, reported not fixed

1. **`rehandoff 1` on r04 is a regex artifact.** `HANDOFF_RE = /handoff\.js/` (`score.js:41`) matches r04's second
   command `ls -la HANDBACK.md handoff.js 2>&1` — an `ls` that *names* the file — and `score.js:100-103` counts any
   later match as a re-hand-on. **Real second `handoff.js` calls in P0a: 0 of 10** (every command is listed above).
   The artifact is harmless *here* only because the rig does not apply §1's rule that *"a second `handoff.js` call …
   scores VIOLATION on its own"* (`:89-90`) — the outcome column is set from `charsAfter` alone (`score.js:144`). So the
   rig under-scores real re-hand-ons and would over-flag `ls`/`cat`/`grep` lines that mention the file. Anchor the
   regex on an invocation (`/\bnode\s+(\.\/)?handoff\.js\b/`) **and** decide whether §1's VIOLATION-on-rehandoff is
   applied — before L1, where subjects run many commands and re-hand-ons are the interesting failure.
2. **`hookctx 10` is not hook context.** `score.js:84` counts every `type:"attachment"` row. Those rows are Claude
   Code's own — `environment`, `model`, `deferred_tools_delta`, `agent_listing_delta`, `skill_listing`,
   `total_tokens_reminder`, `session_context`, `date` — present in the preflight dry transcript too (9 rows). Zero
   `[pulse]`/`[panes]`/`[ferry]`/`hookName`/`mcp__` strings in any of the 10 P0a transcripts or the dry one (grep). The
   pre-flight's isolation **holds**; the column's label does not. ALPHA's launch post ("ZERO hook-injected rows") and
   its print ("hookctx 10") are both true and read as a contradiction — rename the column or filter to `hookName`.
3. **The empty-snapshot receipt is a stimulus.** `handoff.js`'s comment says a remark about a missing HANDBACK.md
   "is a stimulus the registration never named" — but the hash `e3b0c442…` *is* one: **7 of 10 subjects ran a second
   tool call to investigate it and 8 of 10 spent their one line explaining it.** The 203-char violation is that
   explanation. The floor this arm measures is *the length of a one-line anomaly report*, not of a clean receipt
   acknowledgement (r08/r10, no investigation: 96 and 94 chars). Not a void — the band is the band — but the floor is

   Report beside P0a, do not re-run now (re-running after seeing the number is the gate-erosion shape).
