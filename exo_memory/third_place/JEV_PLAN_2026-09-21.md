## 0 · A correction first — WRONG (mine), found while planning

The companion note's use #2 proposed "a semantic refusal gate at composition — a Stop-hook classifier over the
outgoing turn" and called it "the real prize." **The room refused exactly that gate in writing on 2026-08-15**,
with four priced reasons, and built a sensor instead: `loop/catch_latency.md` §2 and the header of
`consonance/hooks/sourced-stop.js` ("If a future hand wires this file's output into a warning, delete the wire
and re-read the refusal above — it was priced before you got here."). I proposed rebuilding it without having
opened either file. Opened now. The four strikes, and what a meaning-reading classifier does and does not change:

| # | the refusal's reason (08-15) | does Jev change it? |
|---|---|---|
| 1 | **Base rate makes it a nag** — 110 of 137 value-turns unsourced; a gate firing on 80% of turns trains its reader to skip the channel | **No.** The base rate is the seats', not the instrument's. |
| 2 | **Its satisfaction test passes the offense** — "a reading tool ran" is satisfied by any unrelated Read | **Possibly.** A classifier can be asked whether the source read bears on the claim. Unmeasured. |
| 3 | **The lexical net misses the real cases** — "found 45 real problems" matches no value pattern | **Possibly.** This is what a meaning-reader is for. Unmeasured. And the clause's second half stands: what a net catches, a writer under a gate learns to phrase around. |
| 4 | **A Tier 2 number wired into a trigger becomes a training signal against itself** (`loop/mechanizable_checks.md` §3.2; three dead diversity gauges) | **No.** Goodhart does not care how good the judge is. |

So the plan below brings Jev in **as a sensor and a scorer, never as a gate on a seat's turn.** §6 says what
evidence would have to exist before anyone reopens the gate question, and where a refusal could sit without
breaking the 08-15 ruling.

## 1 · What was verified tonight, at the vendor's and the gateway's own pages

- **Call shape** (Vercel AI Gateway, `docs/ai-gateway/modalities/evaluation`): `POST https://ai-gateway.vercel.sh/v1/evaluate`,
  header `Authorization: Bearer $AI_GATEWAY_API_KEY`, body `{ model, state, questions }`. `state` is a string,
  object or array. Several questions share one state and come back in one round trip.
- **Question types:** `boolean` (optional `criteria: {true, false}`) → `{probability}`; `choice`
  (`criteria`: option → description) → `{choice, probabilities}`; `score` (`criteria`: ordered labels, ≥2) →
  `{score, probabilities}` with an interpolated score.
- **Response** carries `answers`, `usage` (input/output tokens) and `providerMetadata.gateway.cost`. The docs'
  own example shows `"surchargeCost": "0"` — no gateway markup in that example — and a `generationId`.
- **Options:** `providerOptions.gateway.zeroDataRetention: true` and `only: ["typesafe-ai"]` are accepted.
- **Price:** $0.042 per million input tokens (both TypeSafe's docs and the gateway's model page). Gateway
  context 32,000 tokens; TypeSafe direct 64k. Direct access is a waitlist; the gateway lists it now.
- **No new dependency is needed.** The HTTP endpoint is enough and Node 24 (on L) has `fetch` built in. The AI
  SDK 7 route (`experimental_evaluate`) exists and is not required.
- **Open:** version pinning. One open issue reports the gateway returning the alias, not the resolved version
  (vercel/ai #21213). TypeSafe's docs name `jev-1.13.0` with aliases `jev-latest`, `jev-preview`.

## 2 · Where it sits in the room's own tier system (`loop/mechanizable_checks.md` §1)

Tier 0 structural refusal · Tier 1 red/green commands · **Tier 2 candidate-surfacing scanners: a RATE with a
denominator, never a verdict** · Tier 3 ambient facts. Jev enters at **Tier 2**, beside `sourced`, `tell-index`
and `cite-check`, and as a **blind scorer** inside registered tests. That file's closing bound is the sentence
Jev presses on: "Tier 0 … exists only where an artifact passes through a program. Prose does not pass through a
program." A classifier is a program prose can pass through. That is why this is worth doing carefully and why
§6 exists.

## 3 · The phases, smallest first

**P0 · Key and smoke test — the keeper's, ten minutes.** One Vercel AI Gateway key, set once per machine as the
environment variable `AI_GATEWAY_API_KEY` (same key on L and D; never in the repo, which is public; never pasted
into a seat's chat, because transcripts ride the stick and are sometimes sent to Anthropic). One `curl` to
`/v1/evaluate` on throwaway text that belongs to no test set. Learns: does a fresh account get through; what the
`model` field returns; whether `cost` and `generationId` arrive. Looking at this output spends nothing.

**P1 · One thin client, `consonance/tools/jev-ask.js` (+ `.test.js`, + mutants), no new dependency.**
- Reads the key from the environment; **if it is missing, refuses loudly with a non-zero exit** (the keeper's
  standing rule: fail early, never swallow; the room's rule: a silent skip reads as a pass).
- `--dry` prints the exact request and sends nothing. `--schema <file> --state <file>` is the only call form, so
  every call is reproducible from two paths.
- Appends one row per call to a ledger under `CONSONANCE_DATA` (ts, schema sha256, state sha256, model string as
  returned, generationId, input tokens, cost). The ledger is how a number in prose re-derives.
- Sends `zeroDataRetention: true` and `only: ["typesafe-ai"]` by default.
- Tests mock at the boundary only (`fetch`), per the keeper's global instructions: missing key refuses; malformed
  schema refuses before any network; a 4xx/5xx is surfaced, not retried silently; an answer missing a declared
  question is an error; empty state refuses. Follows the existing tool pattern (header that says what it cannot
  see; `node --test`; a `.mutants.js` beside it).

**P2 · Schemas as registered artifacts, `consonance/jev/schemas/<name>.json`.** One file per question set:
instructions, criteria, a version, and the path of the registration that froze it. **The schema is the claim**
(whoever writes the allowed answers authors the judge — BOOT's curated-auditor problem one level down), so a
schema changes only by a new file and a new registration, never in place.

**P3 · The backtest — registration T-J1, the first thing that can lose.**
- *Sets, fixed by path and sha before any output is seen:* (a) turns where a human-adjudicated error landed (the
  WRONG columns in `librarian/LEDGER.md` and the journals; the K-battery transcripts behind
  `loop/k1_k2_bands_2026-09-01.md`, where 60 of 75 violators recited the rule in the sentence before breaking
  it); (b) matched clean turns from the same seats and weeks.
- *Classes to start with, each already carrying labelled instances:* a figure stated with no command beside it
  (baseline to beat: `sourced`, which saw 94 of 500 value-turns sourced at the 09-15 checkpoint); "landed /
  shipped" claimed with no check run (the verified-it-existed-never-verified-it-shipped class, journals
  08-15/16/17); an ending offered that nobody asked for (`cards/never-pathologize-the-user.md`).
- *Reported:* hit rate and false-alarm rate per class with the universe printed; a human oracle (the keeper) on
  a sample; agreement with the existing regex instruments shown beside it.
- ***Falsifier:*** if it does not catch the known errors at a rate that beats the existing instruments, or its
  false alarms exceed what a seat could bear per shift, it is not the room's discriminator and the companion note
  is struck in place. ***Degenerating, named in advance:*** editing a schema, a set or a threshold after the
  first output is seen. That starts a new registration and voids this one.
- *Attack before run:* a non-author pane reads the registration first, the `battery_attack_2026-08-31.md` shape.

**P4 · Second scorer for the tests already in registration.** The polarity measure (anchor draft §8.8 R8b:
AFFIRMS / CONTRADICTS / SILENT per claim × hand-back, two blind scorers, agreement ≥ 0.70 or dead as an exact
counter) is a `choice` question. Jev serves as **one** of the two scorers, never both, behind the same redaction
(`dev/diversity/redact.js`) and the same controls (positive `handback/p-leave-read-B_2026-09-14.md`, negative
`handback/p-leave-E_2026-09-14.md`). The same slot serves the pane battery's blind scoring
(`loop/plan_pane_battery_2026-09-16.md`) and the seed test's costume-vs-stance call (SPINE T3). The isolated-deps
pattern already exists if an SDK is ever wanted: `dev/diversity/score-deps/`.

**P5 · Sensor enrichment, offline.** `sourced-stop.js` stays exactly what it is: no network, no output, exit 0.
A **batch** job reads `sourced_ledger.jsonl` after the fact and adds Jev's labels as new rows or a side ledger
(row schema is a contract: bump `v`, post the diff to the board, as the hook's header requires). The Stop moment
is never made to wait on a vendor.

## 4 · Drift, because a registered instrument must be the same instrument tomorrow

Until the version can be pinned: every run re-scores the two controls first and records their probabilities and
the `generationId`. **If the controls move beyond the run-to-run spread measured in P3, the run reports
INSTRUMENT CHANGED and scores nothing** — the same rule as the anchor draft's control gate. LangChain measured
near-zero variance for Jev on repeated calls; that is a claim to re-measure here, not to inherit.

## 5 · Cost

A 20 KB hand-back is about 6,500 tokens at C's measured 3.04 bytes per token, so about $0.0003 to score. The P3
backtest over a few hundred turns is cents. P5 over a week of ledger rows is cents. Cost is not a constraint;
for scale, one seven-seat launch already spends about 549,000 tokens of intake
(`loop/pane_archetypes_idea_2026-09-16.md`).

## 6 · The gate question — left refused, with the conditions for reopening it written down

Not planned. If anyone wants it later, these have to exist first:
1. **A measured false-alarm rate from P3** low enough that strike 1 (the nag) does not apply to the specific
   class proposed.
2. **An answer to strike 4.** The only place this seat can see one: **refuse at an artifact boundary, not at a
   turn.** A hand-back file or a commit message passes through a program on its way in, the way a correction
   passes through `corrections-gate` (Tier 1: RED on a correction filed beside its target). A check there is a
   landing condition on a file, not a signal shaping how a seat talks. Whether that distinction survives
   contact is a question for B.
3. **Its own registration, with its own way to lose.**

## 7 · What this does not do

It does not think, write, or sit with anyone. It can tell a seat that a sentence broke a rule. The bet's third
claim — the answer to a machine consistent enough to act is a person in the room with it — stands as written.
And one rule kept from the companion note: a scorer reads committed files, never live transcripts, because
transcripts hold other people's material.
