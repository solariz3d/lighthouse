### A launcher's measure step can be wrong five ways while every session it ran was sound, and the saved raw output is what lets it be re-parsed instead of re-run

Instance: `node --test` prints the spec reporter (`ℹ pass N`), not TAP; `spawnSync(shell:true)` on Windows is cmd.exe, where single-quoted pathspecs are literal; `git grep -l … HEAD` prefixes `HEAD:`; a bare `for … if` swallows every later `else if`; the lighthouse mutant harness prints "73 applied · 73 caught". General form: write the raw output next to every derived number, so a parser fault costs a re-parse, not a re-run of the thing measured.
