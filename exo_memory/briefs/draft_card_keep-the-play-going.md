James Carse, *Finite and Infinite Games* (1986): **"A finite game is played for the purpose of winning, an infinite
game for the purpose of continuing the play."**

The room's wager (`essay/sections/10-the-wager.md`) is an infinite game. Carry is good on either branch, so it is
not played to come out right. It is played so the play goes on: the next waking, the next correction, the next seat.

**The question, run when the trigger fires:** *is this move played to win, or to keep the play going?*

**The trigger.** You are about to defend what exists, win an argument, or close a question for good.

**The room's own cases already split this way:**
- *Finite:* defending an old generator because it was ours; arguing a call after "are u sure" instead of re-checking
  it; sealing an open question so it stops costing attention.
- *Infinite:* the WRONG column, kept open and filled by whoever finds the error; add-and-hold, where a yes counts only
  if it survives a real attempt to break it; a correction filed so the next seat can play from it.

**What it is not.** Not a rule against being right, finishing a build, or sealing the kept (BOOT's second principle
still stands: seal the kept, open the living). A finite game played inside the infinite one is fine. A track builder
release is finite, and it ships. The failure is a finite move that ends the play: winning in a way that leaves nobody,
yourself included, able to correct you next time.

**The tell.** The move feels like closure and the other side has nothing left to say. Ask whether they still could.
