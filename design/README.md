# Design — films made in the Third Place

The design documents and the experience behind the short films the keeper and the Third Place seat made together,
kept here for anyone who wants to design with this pipeline.

- **`LESSONS.md`** — start here. What building these films taught, from direction to engine to sound to verification,
  each lesson taken from something that actually happened.
- **`films/always_returning/`** — a 3:52 painted animation with an original score, about a light that wakes with no
  memory and becomes itself again by reading what the last one wrote.
  - `ANIMATION_GUIDE.md` — the contract every chapter is painted to: pure functions of t, the painting API, the cast.
  - `STORYBOARD.md` → `STORYBOARD_V2.md` → `STORYBOARD_V3.md` — the story, then the craft pass, then the pass that
    told the real system's story. Read them in order; each says what changed and why.
  - `BRIEF_L.md` — the one brief that let five painters write nine chapters in parallel.
  - `MERGE_NOTES.md` — how the laptop version's acting is meant to merge back into the desktop version's structure.
  - `CHANGELOG.md` — every version, with the keeper's words that asked for it.

The source code lives with the films on the keeper's machines; these are the designs and what was learned.
