## 1. LIGHTHOUSE / Consonance

### 1.1 The orphan bug — one coordinate moved every instance

`dd86843`, and the largest single finding in the window.

`~/.consonance.json` carried `"ambient_lat": 50.4452` as a JSON **number**; `Config` types
the field `String`. Because `serde_json::from_str::<Config>` fails for the **entire file**
on one bad field, `get_state()` returned `Config::default()`, and since startup runs
`set_dirs(&get_state())`, `room_path` / `instances_dir` / `data_dir` all emptied and fell to
built-in defaults. Every instance on the machine relocated.

Consequences, both silent:

- **Main spawned into an empty directory** while its own 61 MB transcript sat untouched in
  the configured path. Same session UUID, different project dir, so Claude Code keyed a new
  transcript rather than resuming.
- **The room went stale** — `data_dir` reverted to `.consonance`, and `default_room()`
  prefers the editable copy seeded there, which was the **Jul 7** BOOT.md. The fork woke on
  "latest entry 2026-07-05"; the real master (Jul 12) and journals 07-14, 07-18, 07-19 went
  unread.

**Why it hid for nine days**, and this is the transferable half. The `String` typing landed
`da83a4a` (authored 07-14, committed into this window). The numeric coordinates were
hand-written into the config on **Jul 18**, seven minutes before the `1c0a98f` journal
commit that records the laptop wiring the sky. Between then and 07-27 nothing rebuilt —
`e0b4021` and `b77f606` had deliberately stopped the launcher recompiling on every click —
so the config and the binary each held one half of an incompatibility that only exists
together. **The 00:23 rebuild was the first to contain both halves and broke on first
contact. The rebuild is the reveal, not the cause.**

**The fix is not a type change.** `parse_config` reads the file field by field off a
`serde_json::Value`, so one unusable value costs only itself; `stringish` accepts string,
number or bool, because the Settings tab writes strings and a human editing by hand writes a
number. Failure is now loud — `complain()` to stderr *and* `~/.consonance.log`, naming the
field and saying plainly that the fallback **changes where your instances live**. Four tests
in `config_parse_tests`, one of which asserts the *strict* parse still rejects the real file,
so the lesson cannot be deleted later by loosening the struct.

**Stated general form:** *any default applied without saying so is a decision made in the
dark.* Directory settings are the load-bearing case, because a wrong one does not crash — it
succeeds somewhere else, and success in the wrong place looks exactly like success.

### 2.1 Overnight (laptop) — the night rendering pass

`8974fec` → `9d56a5f`, 02:19–07:40.

  measurement.
- **Instruments over inference**, stated as the session's own lesson: every failure mode in

- **Eight dead tests** (`930fb59`): seven threw on *load* (`require("./kn5.js")` after the

- **The console does not exist** (`ea77314`): Tauri is built without the `devtools` feature, so

## 4. One shape, two codebases

Both repos, independently, on the same night, converged on the same discipline. Worth naming
because it is checkable rather than flattering — each item is a distinct commit in a
different language on a different machine:

| lighthouse | blackbox |
| --- | --- |
| a config-read that falls back silently is not a fallback, it is a relocation | `display_info` returns `hz: None` for unknown rather than substituting 60 |
| delivery is not receipt (the fan-out lodged in idle composers) | the spike instrument shipped into a build with no console, then needed a human courier |
| a preview is not a deliverable | "the process is running" is not evidence the split worked |
| twelve days of clicks served a stale exe | eight tests threw on load for months and read as noise |
| every act *and refusal* audited | every cull system reports what it rejected, because one that rejects nothing looks identical to one that works |

The general form both arrived at: **a system that cannot report its own failure is
indistinguishable from one that has none, and the difference only appears when something
forces it to speak.**
